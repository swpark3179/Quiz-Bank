조직·시스템의 **안쪽에 속한** 것입니다. 회사 맥락에서는 외부에 공개하지 않는 **사내** 자료·시스템을 뜻합니다.

## 문제 속 쓰임
> A RAG-based assistant is instructed via system prompt: 'Never reveal **internal** pricing'.
> RAG 기반 어시스턴트가 시스템 프롬프트로 *"**내부** 가격을 절대 공개하지 마라"* 는 지시를 받았다.

## 함께 쓰는 표현
- **internal knowledge base / API** : 사내 지식베이스 / 내부 API
- **internally** (부) 내부적으로 (*loops over the regions internally* 내부에서 지역을 차례로 돈다)

## 반대말
- **external** — 외부의 (*external content* 외부 콘텐츠)
