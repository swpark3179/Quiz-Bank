목록·설정·로그에 들어 있는 **항목 하나, 기재 사항**입니다. 복수형은 *entries* 입니다.

## 문제 속 쓰임
> A team wants project-specific commands available to all engineers using Claude Code on the repo, without adding **entries** to each engineer's user settings.
> 팀은 모든 엔지니어가 프로젝트 전용 커맨드를 쓸 수 있길 원한다. 단, 각 엔지니어의 사용자 설정에 **항목**을 추가하지 않고서.

## 함께 쓰는 표현
- **add an entry** : 항목을 추가하다
- **log entry** : 로그 한 줄(기록 하나)
- **entry point** : 진입점 — 실행이 시작되는 곳

## 시험 포인트
팀 전체가 써야 하는 설정은 개인 사용자 설정에 **항목을 추가**하기보다 저장소에 커밋되는 **프로젝트 수준 설정**(`.claude/` 등)에 둡니다.
