어떤 공간의 **구석구석 전체에**, 또는 어떤 기간의 **처음부터 끝까지 내내** 라는 뜻입니다.

## 문제 속 쓰임
> Test files are spread **throughout** the codebase alongside the code they test.
> 테스트 파일은 테스트 대상 코드 옆에 놓여 코드베이스 **곳곳에** 흩어져 있다.

## 함께 쓰는 표현
- **throughout the codebase / project** : 코드베이스 / 프로젝트 전체에 걸쳐
- **throughout the conversation** : 대화 내내

## 비교
- **throughout** — 범위 *전체에 걸쳐* (곳곳에, 내내)
- **through** — *통과해서*, ~을 거쳐
- **thorough** — 철저한 (철자가 비슷해 헷갈리기 쉬움)

## 시험 포인트
같은 종류의 파일이 코드베이스 **곳곳에** 흩어져 있으면 디렉터리별 CLAUDE.md 로는 규칙을 여러 번 중복해야 합니다. `.claude/rules/` 의 glob 패턴처럼 파일 경로 패턴으로 적용하는 방식이 정답 방향입니다.
