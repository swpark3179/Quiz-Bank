한 번 정해지면 **요청마다 바뀌지 않고 그대로인** 것입니다. 매번 달라지는 부분은 *dynamic* 이라고 합니다.

## 문제 속 쓰임
> Implement prompt caching for the **static** system prompt and core documents
> **정적인** 시스템 프롬프트와 핵심 문서에 프롬프트 캐싱을 적용한다

## 함께 쓰는 표현
- **static content / prefix** : 고정된 내용 / 앞부분
- **static analysis** : 정적 분석 — 코드를 실행하지 않고 검사하는 것

## 반대말
- **dynamic** — 동적인, 상황에 따라 바뀌는

## 시험 포인트
프롬프트 캐싱은 **매번 똑같이 반복되는 앞부분**(시스템 프롬프트, 고정 문서)에 효과가 있습니다. 비용·지연을 줄이라는 문제에서 "정적 부분 캐싱 + 단순 작업은 작은 모델" 조합이 정답 신호입니다.
