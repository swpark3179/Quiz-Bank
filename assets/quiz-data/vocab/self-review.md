결과물을 만든 쪽이 **자기 결과물을 스스로 검토하는** 것입니다. 같은 맥락·가정을 그대로 갖고 보기 때문에 자기 실수를 놓치기 쉽습니다.

## 문제 속 쓰임
> Enable extended thinking in the same session so the **self-review** reasons more carefully before it approves the tests
> 같은 세션에서 확장 사고(extended thinking)를 켜, **자기 리뷰**가 테스트를 승인하기 전에 더 신중하게 추론하게 한다

## 함께 쓰는 표현
- **self-review bias** : 자기 결과물에 관대해지는 편향
- **independent review** : 독립된 검토

## 시험 포인트
같은 세션에 "비판적으로 보라"고 지시하거나 확장 사고를 켜거나 여러 번 투표시키는 보기는 모두 오답입니다. 정답은 **생성 맥락을 공유하지 않는 별도 인스턴스**가 리뷰하게 하는 것입니다.
