1. **대상, 목표** — 작업이 겨냥하는 것 (*target string* 바꿀 대상 문자열, *target structure* 목표 구조)
2. **겨냥하다, 대상으로 삼다** — *target users* 특정 사용자를 겨냥하다

## 문제 속 쓰임
> ...because the **target** string appears on many lines that must all be updated consistently
> **대상** 문자열이 모두 일관되게 바꿔야 하는 여러 줄에 나타나서
> Define the **target** structure as a tool input_schema, force that tool via tool_choice...
> **목표** 구조를 도구의 `input_schema` 로 정의하고, `tool_choice` 로 그 도구를 강제한다

## 함께 쓰는 표현
- **target file / string** : 대상 파일 / 문자열
- **target audience** : 대상 독자
- **targeted** (형) 특정 대상을 겨냥한, 범위를 좁힌
