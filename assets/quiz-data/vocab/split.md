하나를 **둘 이상으로 나누는** 것입니다. 과거·과거분사도 *split* 으로 같습니다.

## 문제 속 쓰임
> **Split** process_refund into process_full_refund and process_partial_credit, each with its own description stating exactly when to use it.
> `process_refund` 를 `process_full_refund` 와 `process_partial_credit` 로 **나누고**, 각 도구의 description에 언제 써야 하는지 정확히 적는다

## 함께 쓰는 표현
- **split A into B and C** : A를 B와 C로 나누다
- **split a task / tool** : 작업 / 도구를 쪼개다

## 비슷한 말
- **divide**, **break down** — 나누다, 세분하다
- **decompose** — (큰 작업을) 하위 작업으로 분해하다

## 시험 포인트
한 도구가 서로 다른 동작을 함께 맡아 모델이 헷갈린다면, **동작별 도구로 나누고 각 설명에 사용 경계를 적는** 보기가 정답입니다.
