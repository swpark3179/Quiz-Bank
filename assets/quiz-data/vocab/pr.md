*Pull Request* 의 약자로, 내가 만든 코드 변경을 **리뷰받고 본 브랜치에 병합해 달라고 올리는 요청**입니다. CI 리뷰 봇 문제에서 자주 나옵니다.

## 문제 속 쓰임
> 결과는 여전히 자유 형식 산문이고, **PR**마다 입력이 다르니 표현도 계속 달라집니다.

## 함께 쓰는 표현
- **open / merge a PR** : PR 을 올리다 / 병합하다
- **review a PR** : PR 을 리뷰하다
- **PR comment** : PR 에 다는 코멘트

## 비슷한 말
- **MR (merge request)** — GitLab 에서 쓰는 같은 개념
