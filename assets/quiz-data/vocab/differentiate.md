둘 이상의 대상 사이의 **차이를 드러내 서로 구별되게 하는** 것입니다. 문제에서는 설명이 비슷한 두 도구를 **헷갈리지 않도록 설명을 차별화한다**는 뜻으로 나옵니다.

## 문제 속 쓰임
> Expand and **differentiate** both tool descriptions with input formats, example queries, source coverage, and clear boundaries.
> 두 도구 설명을 입력 형식, 예시 쿼리, 다루는 출처 범위, 명확한 사용 경계를 담아 확장하고 서로 **구별되게 한다**

## 함께 쓰는 표현
- **differentiate A from B** / **differentiate between A and B** : A와 B를 구별하다
- **differentiation** (명) 구별, 차별화

## 비슷한 말
- **distinguish** — 차이를 알아보고 구별하다 (거의 같은 뜻)

## 시험 포인트
모델이 도구를 잘못 고르는 원인이 **짧고 서로 겹치는 설명**이라면, 가장 먼저 할 일은 설명을 구체적으로 늘리고 **서로 구별되게** 다시 쓰는 것입니다. 라우팅 분류기를 따로 붙이는 것보다 앞선 첫 단계입니다.
