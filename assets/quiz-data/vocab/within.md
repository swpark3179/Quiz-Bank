## 문제 속 쓰임
> ...Claude Code generates test cases and then, **within** the same session, reviews those tests for quality.
> Claude Code가 테스트 케이스를 생성한 뒤, 같은 세션 **안에서** 그 테스트의 품질을 리뷰한다.

## 함께 쓰는 표현
- **within the same session / context** : 같은 세션·컨텍스트 안에서
- **within a limit** : 한도 안에서 · **within 5 minutes** 5분 이내에

## 시험 포인트
같은 세션 **안에서** 자기 결과를 리뷰하면 편향 때문에 문제를 잘 찾지 못합니다. **독립된 별도 인스턴스**로 리뷰하는 보기가 정답입니다.
