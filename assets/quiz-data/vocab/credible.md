출처·주장이 **믿을 만한 근거와 평판을 갖춘** 상태를 말합니다. *반드시 맞다*가 아니라 *믿을 만해 보인다*는 평가라는 점에 주의합니다.

## 문제 속 쓰임
> The document analysis agent discovers that two **credible** sources contain directly conflicting statistics.
> 문서 분석 에이전트가 **신뢰할 만한** 두 출처에서 정면으로 충돌하는 통계를 발견한다.

## 함께 쓰는 표현
- **credible source / evidence** : 믿을 만한 출처·근거
- **credibility** (명) 신뢰성 · **source credibility** 출처 신뢰도
- **lose credibility** : 신뢰를 잃다

## 시험 포인트
둘 다 credible 한 출처의 값이 서로 다르면, 신뢰도 휴리스틱으로 **한쪽만 골라 버리는 보기는 오답**이 되기 쉽습니다. 두 값을 출처와 함께 남기고 충돌을 표시해 상위에서 판단하게 하는 쪽이 정답입니다.
