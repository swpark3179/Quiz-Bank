1. **제시하다, 보여 주다** — 정보·결론을 내놓아 보여 준다 (*present A as B*: A를 B인 것처럼 내세우다)
2. **(그 안에) 있는, 존재하는** — *not present in the source* 는 "원문에 들어 있지 않은"

## 문제 속 쓰임
> The synthesis subagent silently picks $6.8B and **presents** it as the single authoritative fact.
> 종합 서브에이전트는 아무 표시 없이 $6.8B를 골라 유일한 권위 있는 사실처럼 **제시한다**.
> ...instruct the model to return null when the value is not **present** in the source.
> 원문에 값이 **없으면** null을 반환하라고 모델에 지시한다.

## 함께 쓰는 표현
- **present findings** : 발견 사항을 제시하다
- **presence / absence** : 있음 / 없음

## 시험 포인트
출처마다 수치가 다르면 하나를 조용히 골라 제시하지 말고, **두 값을 출처·날짜 주석과 함께 보존**하는 보기가 정답입니다.
