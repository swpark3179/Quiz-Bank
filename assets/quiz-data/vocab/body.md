머리말·설정 같은 앞부분을 뺀 **본 내용(본문)** 입니다. 스킬(`SKILL.md`)에서는 frontmatter 아래에 쓰는 지시문을, HTTP 에서는 요청·응답의 본문을 말합니다.

## 문제 속 쓰임
> Adding the reminder "only write to docs/, never edit source" to the skill **body** has not reliably stopped it.
> 스킬 **본문**에 "only write to docs/, never edit source"(docs/에만 쓰고 소스는 절대 수정하지 말 것)라는 문구를 추가했지만 확실히 막지 못했습니다.

## 함께 쓰는 표현
- **skill body** : 스킬 본문 (frontmatter 아래 지시 부분)
- **request / response body** : 요청 / 응답 본문
- **page bodies** : 웹 페이지 본문들

## 시험 포인트
본문에 적은 지시는 모델이 참고하는 **안내일 뿐 보장이 아닙니다**. "절대 못 하게" 해야 한다면 frontmatter 의 도구 설정처럼 **하네스가 강제하는** 결정적 장치가 정답입니다.
