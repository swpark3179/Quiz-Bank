정해진 기준에 맞는지 **처음부터 끝까지 꼼꼼히 점검하는** 것입니다. 회계에서는 '회계 감사', 개발에서는 **보안 감사(security audit)** 처럼 정기적·종합적인 점검을 가리킵니다.

## 문제 속 쓰임
> ...comprehensive security **audits** run weekly, and (3) test case generation triggered nightly.
> 매주 실행하는 종합 보안 **감사**, 그리고 (3) 매일 밤 실행되는 테스트 케이스 생성.

## 함께 쓰는 표현
- **security audit** : 보안 감사 (취약점을 종합적으로 점검)
- **audit log / audit trail** : 누가 언제 무엇을 했는지 남긴 기록
- **conduct an audit** : 감사를 실시하다

## 비슷한 말
- **review** — 검토 (audit 보다 가볍고 일상적)
- **inspection** — 검사, 현장 점검
