앞에 나온 명사를 받아 "**그것의 ~가**"라고 소유 관계로 이어 주는 말입니다(사람·사물 모두). 의문문에서는 "누구의"입니다.

## 문제 속 쓰임
> Consolidate the two tools into one unified search tool **whose** single description covers both general web pages and academic sources.
> 두 도구를, **설명 하나가** 일반 웹 페이지와 학술 출처를 모두 다루는 통합 검색 도구로 합친다.

## 함께 쓰는 표현
- **a tool whose output** ~ : 출력이 ~인 도구
- **whose** vs **who's** : *who's* 는 *who is* 의 줄임말 (발음 같음)
