## 문제 속 쓰임
> Rename the skill to `/scaffold-component-with-name` so the required input is **implied** by the command name itself
> 스킬 이름을 `/scaffold-component-with-name` 으로 바꿔, 필요한 입력이 명령 이름 자체에서 **드러나게** 한다

## 함께 쓰는 표현
- **be implied by** ~ : ~에서 암시되다, ~로 미루어 알 수 있다
- **implication** (명) 함축, (뒤따르는) 영향

## 비교
- **imply** — 말하는 쪽이 *넌지시 비추다*
- **infer** — 듣는 쪽이 *미루어 짐작하다*

## 시험 포인트
이름으로 사용법을 **암시만 하는** 보기는 형식을 알려 주지도, 잘못된 호출을 막지도 못하는 약한 해법입니다. 이 문제에서는 호출 순간에 기대 인자를 보여 주는 SKILL.md 의 `argument-hint` 가 정답이었습니다.
