무엇을 **통로·수단으로 삼아** 전달하거나 처리하는지 나타냅니다. *through*, *by means of* 와 비슷하며, 문서체에서 짧게 쓰기 좋습니다.

## 문제 속 쓰임
> The skill accepts a migration name **via** `$ARGUMENTS`.
> 이 스킬은 마이그레이션 이름을 `$ARGUMENTS` 를 **통해** 받는다.

## 함께 쓰는 표현
- **via email / API** : 이메일로 / API를 통해
- **via a shared queue** : 공유 큐를 통해
- **travel via Tokyo** : 도쿄를 경유해 가다

## 비슷한 말
- **through**, **by means of** — ~을 통해 (via 가 더 짧고 문서체)
- **by way of** — ~을 거쳐
