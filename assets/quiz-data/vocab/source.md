1. **출처, 근거 자료** — 정보·주장이 어디서 왔는지 (*named sources* 출처 이름)
2. **소스 코드, 원본** — *source files* 는 사람이 작성한 원본 코드 파일

## 문제 속 쓰임
> A shared `generate-docs` skill is supposed to read **source** and write Markdown into `docs/`, but twice it has run `Edit` and shell `rm` and overwritten **source** files.
> 공유 `generate-docs` 스킬은 **소스**를 읽고 `docs/` 에 Markdown을 써야 하는데, 두 번이나 `Edit` 과 셸 `rm` 을 실행해 **소스** 파일을 덮어썼습니다.

## 함께 쓰는 표현
- **source document / text** : 원문 문서 / 텍스트
- **cite a source** : 출처를 밝히다
- **source of truth** : 기준 원본 (따로 등록된 표현)

## 시험 포인트
여러 단계를 거치는 리서치 파이프라인에서는 각 주장에 **출처를 붙인 채(claim–source 매핑) 끝까지 넘겨야** 마지막 보고서가 인용을 달 수 있습니다. 나중에 출처를 다시 찾거나 추측하는 보기는 오답입니다.
