무엇을 해 달라고 **청하는 것(요청)** 입니다. API 에서는 서버로 보내는 호출 한 번을 *request*, 돌아오는 것을 *response* 라고 합니다.

## 문제 속 쓰임
> ...a tool returning ambiguous results can cause the model to keep **requesting** the same tool indefinitely
> 도구가 모호한 결과를 반환하면 모델이 같은 도구를 끝없이 **재요청할** 수 있다.

## 함께 쓰는 표현
- **request payload** : 요청 본문(보내는 데이터)
- **on request** : 요청하면, 요청 시
- **requested tool** : (모델이) 요청한 도구

## 비교
- **request** — 보내는 쪽 (요청)
- **response** — 돌아오는 쪽 (응답)
