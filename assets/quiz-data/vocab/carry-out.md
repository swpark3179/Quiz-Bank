계획·지시·작업을 **실제로 해내는(수행하는)** 것입니다. *do* 보다 격식 있는 말로, 수동형 *carried out* 이 자주 나옵니다.

## 문제 속 쓰임
> During a 200-file framework migration **carried out** in one long session, logs show Claude re-migrating files it already converted...
> 하나의 긴 세션에서 파일 200개 규모의 프레임워크 마이그레이션을 **진행하는** 동안, Claude가 이미 변환한 파일을 다시 마이그레이션하는 모습이 로그에 나타납니다.

## 함께 쓰는 표현
- **carry out a task / migration** : 작업 / 마이그레이션을 수행하다
- **carry out instructions** : 지시를 이행하다

## 비슷한 말
- **perform**, **execute**, **conduct** — 수행하다
