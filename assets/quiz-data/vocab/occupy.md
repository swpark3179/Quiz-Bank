어떤 자리나 공간을 **채워서 다른 것이 쓸 수 없게** 하는 것입니다. 컨텍스트 창 문제에서는 토큰이 창의 공간을 얼마나 쓰는지를 말할 때 나옵니다.

## 문제 속 쓰임
> The cached system prompt, the tool definitions, the history, and the generated output all **occupy** the window; caching changes only what the cached tokens cost.
> 캐시된 시스템 프롬프트, 도구 정의, 대화 기록, 생성된 출력이 모두 윈도를 **차지한다**. 캐싱은 캐시된 토큰의 비용만 바꾼다

## 함께 쓰는 표현
- **occupy the window** : 컨텍스트 창을 차지하다
- **occupy space** : 공간을 차지하다
- **occupied** (형) 사용 중인

## 비슷한 말 · 반대말
- **take up** — 차지하다 (더 일상적, *take up room*)
- **footprint** — 차지하는 크기, 점유 공간

## 시험 포인트
"캐싱하면 컨텍스트 공간이 비워진다"는 보기는 **오답**입니다. 캐시 읽기 토큰을 포함한 모든 입력과 출력이 창을 차지하며, 캐싱은 **비용과 지연만** 줄입니다("캐시 = 싸게"이지 "캐시 = 작게"가 아님).
