기본으로 주어진 것이 아니라 **사용자가 필요에 맞게 직접 만들거나 정한** 것입니다. 동사 *customize* 는 "맞춤 설정하다"입니다.

## 문제 속 쓰임
> Create a **custom** slash command `/lint` that the developer runs manually after edits
> 개발자가 편집 후 수동으로 실행하는 `/lint` **커스텀** 슬래시 커맨드를 만든다
> `stop_sequence` — a **custom** stop string was matched
> `stop_sequence` — **지정한** 중단 문자열과 일치했다

## 함께 쓰는 표현
- **custom tool / MCP tool** : 직접 만든 도구
- **customize** (동) 맞춤 설정하다 · **customization** (명) 맞춤 설정

## 시험 포인트
"매번 **자동으로**" 실행해야 하는 일에 사람이 손으로 돌리는 커스텀 슬래시 커맨드를 고르면 오답입니다. 이 경우는 **hooks** 가 정답입니다.
