## 문제 속 쓰임
> Tool execution stays in Anthropic's cloud sandbox, and the worker only **mirrors** session files into the bank's network afterward.
> 도구 실행은 Anthropic 클라우드 샌드박스에 그대로 있고, 워커는 나중에 세션 파일을 은행 네트워크로 **복제해 두기만** 한다

> Provide 3 to 5 examples that **mirror** real notes, vary in phrasing, include edge cases...
> 실제 메모를 **닮고**, 표현이 다양하며, 엣지 케이스를 포함한 예시 3~5개를 제공한다

## 함께 쓰는 표현
- **mirror real data** : 실제 데이터를 닮다
- **mirror files / a repository** : 파일·저장소를 그대로 복제하다

## 시험 포인트
자체 호스팅 샌드박스로 옮겨 오는 것은 **도구 실행 자체**라서, 워커가 파일을 복제만 한다는 보기는 오답입니다. 예시 문항에서는 "실제와 닮음·3~5개·다양함(엣지 케이스)·`<example>` 태그"가 정답 신호입니다.
