다른 대상이 지켜야 하는 규칙·검사·의무에서 **예외로 빠진다**는 말입니다. *be exempt from* ~ 꼴로 "~에서 면제되다"라고 씁니다.

## 문제 속 쓰임
> Read-only commands are permanently **exempt** from every permission mode in Claude Code, no matter which mode is currently active
> 읽기 전용 명령은 현재 어떤 모드든 상관없이 Claude Code의 모든 권한 모드에서 영구히 **면제된다**.

## 함께 쓰는 표현
- **be exempt from** ~ : ~에서 면제되다
- **exempt A from B** : A를 B에서 면제하다
- **exemption** : 면제, 예외

## 비슷한 말 · 반대말
- **excluded** — 제외된 (범위에서 빠짐)
- **subject to** ~ — ~의 적용을 받는

## 시험 포인트
"항상·영구히 *exempt*"처럼 예외를 단정하는 보기는 의심하세요. 읽기도 모든 검사에서 빠지지는 않아, `permissions.blockReadsOutsideWorkingDirectories` 가 켜져 있거나 명시적 ask 규칙이 있으면 프롬프트가 뜹니다.
