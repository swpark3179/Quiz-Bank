1. **(말을) 주고받기, 한 차례 대화** — 질문과 답이 한 번 오가는 단위 (*a short exchange*)
2. **(상품) 교환** — 산 물건을 다른 사이즈·색 등으로 바꾸는 일
3. **주고받다, 교환하다** — 데이터·메시지·이벤트를 서로 보내고 받는다

## 문제 속 쓰임
> In testing, a furious customer with a routine 30-day size **exchange** gets escalated.
> 테스트에서 일반적인 30일 사이즈 **교환**을 요청한 몹시 화난 고객은 사람에게 넘겨졌다.

> A hosted agent harness where Anthropic runs the loop in a cloud sandbox and the app **exchanges** events with it.
> Anthropic이 클라우드 샌드박스에서 루프를 돌리고 앱은 이벤트를 **주고받는** 호스팅형 에이전트 하네스다.

## 함께 쓰는 표현
- **size exchange** : 사이즈 교환
- **exchange events / messages** : 이벤트·메시지를 주고받다
- **in exchange for** ~ : ~의 대가로

## 시험 포인트
화난 고객의 일상적인 *exchange* 처럼 **감정은 나빠도 정책으로 처리할 수 있는 요청**은 사람에게 넘길 이유가 아닙니다. 이관은 고객의 사람 요청, 정책 공백, 진행 불가처럼 확인할 수 있는 조건으로 정합니다.
