내용은 살리면서 **짜임새(구조)를 바꿔 다시 짜는** 것입니다. 조직 개편, 코드 재구성, 입력 배치 변경 등에 두루 씁니다.

## 문제 속 쓰임
> How should you **restructure** the aggregated input?
> 집계된 입력을 어떻게 **재구성해야** 하는가?

## 함께 쓰는 표현
- **restructure the code / review** : 코드 / 리뷰 방식을 재구성하다
- **restructure A into B** : A를 B 형태로 바꿔 짜다
- **restructuring** (명) 재구성, 구조 조정

## 비슷한 말
- **reorganize** — 다시 정리·편성하다
- **refactor** — (코드) 동작은 그대로 두고 내부 구조를 고치다
- **rearrange** — 배치·순서를 바꾸다
