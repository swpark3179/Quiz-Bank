> Add few-shot examples of **misleading** comments to help the model recognize similar patterns

## 함께 쓰는 표현
- **misleading comment / documentation** : 실제 동작과 달라 오해를 부르는 주석·문서
- **mislead** (동) 잘못 이끌다, 오해하게 하다 (과거형 *misled*)

## 비교
- **false** — 내용 자체가 틀린
- **misleading** — 틀리지 않았더라도 잘못된 인상을 주는

## 시험 포인트
어떤 주석이 **misleading** 한지 가려내게 하려면 예시보다 먼저 **판단 기준**을 분명히 해야 합니다. 예: "주석이 설명하는 동작이 실제 코드 동작과 모순될 때만 표시한다."
