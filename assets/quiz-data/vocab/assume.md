확인하지 않은 채 **사실이라고 여기거나 전제로 삼는** 것입니다. 명사는 *assumption*(가정, 전제)입니다.

## 문제 속 쓰임
> Instruct the generating session to "review critically and **assume** the code contains bugs" before it approves the diff
> 생성 세션이 diff를 승인하기 전에 "비판적으로 리뷰하고 코드에 버그가 있다고 **가정하라**"라고 지시한다

## 함께 쓰는 표현
- **assume that** ~ : ~라고 가정하다
- **make an assumption** : 가정하다, 넘겨짚다

## 시험 포인트
같은 세션에 "비판적으로 보라"고 **지시만 바꾸는** 보기는 오답입니다. 자기 결과물에 대한 편향을 없애려면 컨텍스트를 공유하지 않는 **독립 리뷰 인스턴스**가 필요합니다.
