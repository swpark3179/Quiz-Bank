여러 단계나 과정을 거친 뒤 **맨 마지막에 가서는, 결국**이라는 뜻입니다. 겉으로는 여러 갈래처럼 보여도 "근본적으로는 다 이것으로 귀결된다"고 말할 때 씁니다.

## 문제 속 쓰임
> `http`, because every MCP server is **ultimately** reached through its single MCP endpoint.
> `http`. 모든 MCP 서버는 **결국** 단일 MCP 엔드포인트로 접근하기 때문이다.

## 함께 쓰는 표현
- **ultimately responsible for** ~ : 최종적으로 ~에 책임이 있는
- **ultimately decide** : 최종 결정하다
- **ultimate goal** : 궁극적인 목표

## 비슷한 말
- **eventually** — 결국, 마침내 (시간이 흐른 뒤라는 느낌)
- **in the end** — 결국 (일상어)

## 시험 포인트
이 보기는 오답입니다. "모든 MCP 서버는 *ultimately* 하나의 엔드포인트로 접근한다"는 일반화는 틀렸습니다. 단일 MCP 엔드포인트는 Streamable HTTP 서버의 특징이고, **실행 명령만 주어진 서버는 stdio** 로 등록합니다.
