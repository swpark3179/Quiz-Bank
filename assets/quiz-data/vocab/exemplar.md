따라 만들 **기준이 되는 잘 된 본보기**입니다. 그냥 *example*(예)보다 "이대로 따라 하면 된다"는 *모범*의 느낌이 강합니다.

## 문제 속 쓰임
> Add the **exemplar** endpoint code with pattern documentation to the project CLAUDE.md file so it's automatically available.
> **본보기** 엔드포인트 코드와 패턴 문서를 프로젝트 CLAUDE.md 에 넣어 자동으로 쓰이게 한다.

## 함께 쓰는 표현
- **exemplar implementation** : 모범 구현
- **exemplary** (형) 모범적인

## 비교
- **example** — 여러 경우 중 하나를 보여 주는 예
- **exemplar** — 따라야 할 기준이 되는 모범 예시
- **template** — 빈칸을 채워 쓰는 틀

## 시험 포인트
본보기 코드가 **특정 작업에서만** 필요하다면, 항상 로드되는 CLAUDE.md 나 디렉터리 기준으로 켜지는 rules 가 아니라 **필요할 때 호출하는 Skill** 에 넣는 보기가 정답입니다.
