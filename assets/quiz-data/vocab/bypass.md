정해진 경로·절차를 **거치지 않고 옆으로 돌아가는** 것입니다. 설계 문제에서는 대개 **통제·검증 지점을 건너뛴다**는 부정적인 뉘앙스로 나옵니다.

## 문제 속 쓰임
> Each agent directly sends its findings to the report generation agent, **bypassing** the coordinator.
> 각 에이전트가 코디네이터를 **거치지 않고** 보고서 생성 에이전트로 결과를 직접 보낸다.

## 함께 쓰는 표현
- **bypass the coordinator / a check** : 코디네이터·검사를 건너뛰다
- **bypass a restriction** : 제한을 우회하다
- **bypass** (명) 우회로

## 시험 포인트
허브 역할을 하는 코디네이터를 **bypass 하는 직접 통신** 선택지는 대개 오답입니다. 코디네이터를 거쳐야 모든 상호작용을 관찰하고, 오류를 일관되게 처리하고, 각 에이전트가 받을 정보를 통제할 수 있기 때문입니다.
