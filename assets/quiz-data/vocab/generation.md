## 함께 쓰는 표현
- **code generation** : 코드 생성
- **test generation** : 테스트 생성
- **retrieval-augmented generation (RAG)** : 검색 증강 생성

## 시험 포인트
코드를 **생성한 같은 세션**이 리뷰까지 하면 자기 결과를 관대하게 보므로, 리뷰는 맥락을 공유하지 않는 **별도의 독립 인스턴스**에서 돌리는 보기가 정답입니다.
