여러 가지를 **섞어 하나로 만드는** 것입니다. *blended* 는 "섞인, 혼합된" — 문제에서는 서로 다른 두 출처의 수치를 평균 내 만든 **혼합 수치**를 가리킵니다.

## 문제 속 쓰임
> Average the two figures into a single **blended** market-size number so the report reflects both sources about equally.
> 보고서가 두 출처를 거의 같은 비중으로 반영하도록, 두 수치를 평균 내 하나의 **혼합** 시장 규모 수치로 만든다.

## 함께 쓰는 표현
- **blend A with B** : A와 B를 섞다
- **a blend of** ~ : ~이 섞인 것

## 시험 포인트
출처마다 수치가 다를 때 평균 내 **섞어 버리는** 보기는 오답입니다. 먼저 시점·출처 차이인지 보고, 두 값을 **출처·발행 날짜 주석과 함께 둘 다 보존**하는 보기가 정답입니다.
