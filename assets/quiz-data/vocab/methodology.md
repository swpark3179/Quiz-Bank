연구·분석을 **어떤 절차와 기준으로 했는지**에 대한 설명입니다. 보고서·논문의 *Methodology* 절에는 데이터를 어떻게 모으고 분석했는지가 적힙니다.

## 문제 속 쓰임
> In a research assistant, a user pastes the link to a 40-page PDF report and asks for a critique of its **methodology** section.
> 한 리서치 어시스턴트에서 사용자가 40쪽짜리 PDF 보고서 링크를 붙여 넣고 **방법론** 절을 비평해 달라고 요청합니다.

## 함께 쓰는 표현
- **methodology section** : (보고서의) 방법론 절
- **research methodology** : 연구 방법론

## 비슷한 말 · 반대말
- **method** — 하나하나의 구체적 방법. *methodology* 는 그 방법들의 체계입니다
- **approach** — 접근 방식

## 시험 포인트
*methodology* 는 무엇을 비평할지 알려 주는 배경이고, 핵심은 **알려진 URL 의 전체 내용(PDF 포함)을 서버가 가져오는** web fetch 도구입니다. web search 는 검색 결과 목록을 돌려줄 뿐이라 오답입니다.
