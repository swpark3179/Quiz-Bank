**여러 파일에 걸쳐** 이루어지는 것입니다. 한 파일 안에서만이 아니라 파일 경계를 넘어 심볼·참조·변경을 찾거나 다룰 때 씁니다.

## 문제 속 쓰임
> The team added a code-intelligence MCP server that does semantic, **cross-file** symbol search over an indexed monorepo.
> 팀이 인덱싱된 모노레포에서 의미 기반의 **파일 간** 심볼 검색을 하는 코드 인텔리전스 MCP 서버를 추가했습니다.

## 함께 쓰는 표현
- **cross-file references** : 파일 사이의 참조
- **cross-** ~ : ~를 가로지르는 (*cross-team*, *cross-platform*)

## 시험 포인트
MCP 도구가 내장 `Grep` 에 밀려 잘 쓰이지 않으면, 먼저 **도구 설명에 예시 쿼리와 "문자열 매칭이 놓치는 의미 기반 파일 간 검색"이라는 경계**를 보강하는 것이 첫 단계입니다.
