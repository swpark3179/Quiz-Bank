다른 일과 섞지 않고 **한 가지 용도만 맡도록 따로 둔** 것을 말합니다. 사람에게 쓰면 "헌신적인"이라는 뜻도 있습니다.

## 문제 속 쓰임
> Create a **dedicated** error-handling agent that monitors all subagent failures via a shared queue.
> 공유 큐로 모든 서브에이전트 실패를 감시하는 **전용** 에러 처리 에이전트를 만든다.

## 함께 쓰는 표현
- **dedicated server / agent** : 한 가지 일만 하는 전용 서버·에이전트
- **dedicated to** ~ : ~ 전용인, ~에 전념하는
- **dedicated team** : 전담 팀

## 시험 포인트
"전용 ○○ 에이전트를 새로 만든다"는 보기는 **구성 요소만 늘리는 과잉 설계**가 아닌지 의심해 보세요. 오류 처리라면 해결할 수 있는 가장 낮은 수준에서 처리하는 더 단순한 보기가 우선입니다.
