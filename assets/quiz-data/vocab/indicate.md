증거나 신호가 **어떤 사실을 가리켜 보여 주는** 것입니다. 로그·데이터가 주어면 "~임을 보여 주다", 사람·시스템이 주어면 "~을 표시하다, 알리다"로 옮기면 자연스럽습니다.

## 문제 속 쓰임
> Logs **indicate** Claude Code is waiting for interactive input.
> 로그는 Claude Code가 대화형 입력을 기다리고 있음을 **보여 준다**.
> ...without **indicating** which data was unavailable.
> 어떤 데이터가 없었는지는 **표시하지** 않는다.

## 함께 쓰는 표현
- **indicate that** ~ : ~임을 보여 주다, 나타내다
- **indicator** (명) 지표, 표시 · **indication** (명) 징후, 조짐

## 시험 포인트
일부 소스가 실패했을 때 **무엇이 빠졌는지 표시하지 않고** 진행하는 선택지는 오답입니다. 어떤 결과가 충분히 뒷받침되고 어디에 공백이 있는지 드러내는 쪽이 정답입니다.
