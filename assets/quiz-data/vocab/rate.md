1. **평가하다, 점수를 매기다** — *rate A (as) B* "A를 B로 평가하다"
2. **비율, 속도, 요금** — *error rate* 오류율, *batch rate* 배치 요금

## 문제 속 쓰임
> It consistently **rates** its own output clean, yet human reviewers keep finding real bugs it missed.
> 이 세션은 자기 결과물을 늘 문제없다고 **평가하지만**, 사람 리뷰어는 세션이 놓친 실제 버그를 계속 찾아낸다.

## 함께 쓰는 표현
- **error / success rate** : 오류율 / 성공률
- **rate limit** : (API) 요청 횟수 제한
- **rating** (명) 평가 점수, 등급

## 시험 포인트
같은 세션이 만든 코드를 스스로 평가하면 늘 통과시키기 쉽습니다. 컨텍스트를 공유하지 않는 **독립 리뷰 인스턴스**가 정답이고, 모델이 **스스로 매긴 점수** 임계값에 기대는 보기는 오답이 되기 쉽습니다.
