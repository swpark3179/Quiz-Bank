해석이 둘 이상으로 갈려 판단하기 어려운 상태입니다. 시험에서는 주로 *요청이 애매해 어떤 도구로 보낼지 헷갈리는* 상황에 나옵니다.

## 문제 속 쓰임
> ...particularly for **ambiguous** requests like "I need help with my recent purchase".
> "최근 구매 건으로 도움이 필요해요" 같은 **모호한** 요청에서 특히 그렇다.

## 함께 쓰는 표현
- **ambiguous request / input** : 어느 도구·처리로 보내야 할지 애매한 요청
- **ambiguity** (명) 모호함 · **resolve ambiguity** 모호함을 해소하다

## 반대말
- **unambiguous**, **explicit**, **clear** — 해석이 하나로 분명한
