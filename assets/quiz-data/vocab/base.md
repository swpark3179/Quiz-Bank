1. **기반, 바탕 / (지식) 베이스** — *knowledge base*(지식베이스), *codebase*(코드베이스)
2. **~에 기반을 두다** — *be based on* (~을 바탕으로 하다), *Claude-based* (Claude 기반의)

## 문제 속 쓰임
> A company deploys an MCP server that gives Claude access to internal knowledge **bases** and HR systems.
> 한 회사가 Claude에게 사내 지식**베이스**와 HR 시스템 접근 권한을 주는 MCP 서버를 배포했습니다.

## 함께 쓰는 표현
- **knowledge base** : 지식베이스 (사내 문서 모음)
- **base model** : (파인튜닝 전) 기본 모델
- **based on** ~ : ~을 바탕으로
