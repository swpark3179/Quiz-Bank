1. **(내용이) 빈약한, 부실한** — 양이나 깊이가 모자라 **알맹이가 별로 없는** 상태입니다 (*findings came back thin* 결과가 빈약하게 돌아왔다)
2. **얇은, 가벼운** — 두께가 얇거나, 소프트웨어에서 **기능을 최소한만 얹은** 층 (*thin client*, *thin wrapper*)

## 문제 속 쓰임
> The subagents had restricted access to external search tools, so their findings on the areas they were assigned came back **thin**
> 서브에이전트의 외부 검색 도구 접근이 제한돼, 배정된 영역에 대한 결과가 **빈약하게** 돌아왔다

> A **thin** API client where the team defines each tool schema, executes every tool, and writes the tool-use loop itself.
> 팀이 도구 스키마를 정의하고, 모든 도구를 실행하고, 도구 사용 루프도 직접 작성하는 **얇은** API 클라이언트다.

## 함께 쓰는 표현
- **thin wrapper** : 기능을 거의 더하지 않은 얇은 감싸기 층
- **come back thin** : (결과가) 빈약하게 돌아오다

## 비슷한 말 · 반대말
- **sparse** — 드문드문한, 빈약한
- **thorough** — 철저한, 빠짐없는

## 시험 포인트
보고서에서 주제가 **통째로 빠졌다면** 결과가 *thin* 한 품질 문제가 아니라, 그 주제를 아무에게도 배정하지 않은 **분해(커버리지) 실패**입니다. 검색 도구 제한을 원인으로 든 이 보기는 오답입니다.
