이미 있는 것을 **더 좋게·더 강하게 보강하는** 것입니다. 새로 만드는 게 아니라 *기존 것에 덧붙여 개선한다*는 느낌입니다.

## 문제 속 쓰임
> **Enhance** the system prompt to state that customer verification via `get_customer` is mandatory before any order operations.
> 시스템 프롬프트를 **보강해** 주문 작업 전 `get_customer` 고객 확인이 필수라고 명시한다.

## 함께 쓰는 표현
- **enhance performance / quality** : 성능·품질을 높이다
- **enhancement** (명) 개선, 기능 강화 (이슈 라벨 *enhancement*)
- **enhanced** (형) 향상된, 강화된

## 비슷한 말
- **improve** — 가장 일반적인 "개선하다"
- **augment** — 기능·양을 *더해서* 늘리다

## 시험 포인트
프롬프트를 보강해 "필수"라고 적어도 모델이 가끔 어길 수 있습니다. 순서를 반드시 지켜야 한다면 **프로그램적 전제조건**으로 막는 보기가 정답입니다.
