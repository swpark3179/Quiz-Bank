단어와 그 뜻·대응값을 **짝지어 모아 둔 목록**입니다. 문제에서는 같은 뜻의 여러 표현을 하나의 표준 표현으로 맞추는 **동의어 사전**으로 나옵니다. 프로그래밍에서는 키-값 자료형(Python `dict`)도 이렇게 부릅니다.

## 문제 속 쓰임
> Add a post-processing library with a synonym **dictionary** that normalizes severity wording before the grep step runs
> grep 단계가 실행되기 전에 동의어 **사전**을 가진 후처리 라이브러리를 추가해 심각도 표현을 정규화한다

## 함께 쓰는 표현
- **synonym dictionary** : 동의어 사전 — 여러 표현을 표준 값 하나로 바꿀 때 씀
- **data dictionary** : 데이터 사전 — 필드 이름·뜻·형식을 정리한 문서
- **dictionaries** : 복수형 (-ies)
