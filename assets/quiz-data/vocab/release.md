1. **릴리스, 출시(판)** — 소프트웨어의 새 버전을 내보내는 일 또는 그 버전
2. **내보내다, 공개하다** — *release a new version*
3. **풀어 주다, 해제하다** — 잡고 있던 자원·잠금을 놓는다 (*release a lock*)

## 문제 속 쓰임
> A team's `.claude/skills/dep-audit/` skill is meant to be run manually before **releases**...
> 팀의 `.claude/skills/dep-audit/` 스킬은 **릴리스** 전에 수동으로 실행하려고 만든 것이다.

## 함께 쓰는 표현
- **release notes** : 릴리스 노트(버전별 변경 내역)
- **release branch** : 출시용 브랜치
- **pre-release** : 정식 출시 전 버전
