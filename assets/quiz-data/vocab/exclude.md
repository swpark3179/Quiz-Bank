어떤 범위나 목록에서 **빼서 포함하지 않는다**는 말입니다. 도구 설명에서는 "이 도구는 ~에는 쓰지 않는다"처럼 맡지 않는 경우를 밝히는 데 씁니다.

## 문제 속 쓰임
> Rename analyze_content to match the scope it has left, and rewrite its description so it **excludes** web content, which the new tool now handles
> `analyze_content` 를 남은 범위에 맞는 이름으로 바꾸고, 이제 새 도구가 맡은 웹 콘텐츠는 **제외한다**고 설명을 다시 쓴다.

## 함께 쓰는 표현
- **exclude A from B** : A를 B에서 빼다
- **excluding** ~ : ~을 제외하고
- **exclusion** : 제외

## 비슷한 말 · 반대말
- **omit** — 빠뜨리다, 생략하다
- **include** — 포함하다

## 시험 포인트
새 도구를 추가한 뒤에도 요청이 옛 도구로 새면, 옛 도구 이름을 남은 범위에 맞게 바꾸고 새 도구가 맡은 경우를 설명에서 *exclude* 하는 것이 정답입니다. 배열 순서·예시 추가·내부 동작 설명은 겹침을 없애지 못합니다.
