1. **지속적인, 끊김 없이 이어지는** — 멈추지 않고 계속되는 (*Continuous Integration* = 지속적 통합)
2. **continuation** (명) **이어 가기, 이어서 생성** — 끊긴 응답이나 작업을 이어서 계속하는 것

## 문제 속 쓰임

## 함께 쓰는 표현
- **continuous integration (CI)** : 지속적 통합 — 변경을 자주 합치며 자동으로 빌드·테스트
- **continuous deployment (CD)** : 지속적 배포
- **continuously** (부) 끊임없이, 계속

## 비교
- **continuous** — 중간에 끊김이 없는
- **continual** — 자주 되풀이되는 (사이사이 끊김이 있음)
