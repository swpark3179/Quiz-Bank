라이브러리나 자동 생성 도구를 쓰지 않고 **사람이 직접 짠** 코드·규칙을 말합니다. 일상어로는 "손으로 쓴, 손글씨의"입니다.

## 문제 속 쓰임
> ...sometimes it adds zod, sometimes **hand-written** checks, sometimes nothing meaningful.
> 어떤 때는 `zod` 를 추가하고, 어떤 때는 **손으로 쓴** 검사 코드를 넣고, 어떤 때는 의미 있는 변화가 거의 없다.

## 함께 쓰는 표현
- **hand-written checks / validation** : 직접 짠 검사 / 검증 코드
- **hand-rolled** : 직접 만든 (비슷한 말)

## 반대말
- **auto-generated**, **library-based** — 자동 생성된, 라이브러리를 쓴

## 시험 포인트
실행마다 스타일이 들쭉날쭉하다면 설명을 늘리기보다 원하는 방식을 보여 주는 **구체적인 입력-출력 예시 2~3개**(few-shot)를 주는 보기가 정답입니다.
