등급·성능·권한을 **한 단계 낮은 쪽으로 내린다**는 말입니다. 모델 선택에서는 더 작고 싼 모델로 바꾸는 것, 권한에서는 "허용"을 "확인 요청"처럼 약하게 바꾸는 것을 가리킵니다.

## 문제 속 쓰임
> Start with Claude Fable 5.1 → measure quality → **downgrade** one tier each week → stop when users start to complain
> Claude Fable 5.1로 시작 → 품질 측정 → 매주 한 티어씩 **낮춤** → 사용자 불만이 나오면 멈춤

## 함께 쓰는 표현
- **downgrade the model** : 더 낮은 등급의 모델로 바꾸다
- **be downgraded to** ~ : ~로 낮춰지다

## 비슷한 말 · 반대말
- **step down** — 한 단계 내려가다
- **upgrade** — 올리다, 상위 등급으로 바꾸다

## 시험 포인트
효율 우선은 "작은 모델로 시작 → 테스트 → 평가 → **격차가 있을 때만** *upgrade*" 순서이고, *downgrade* 는 Opus 5.5로 시작하는 성능 우선에서 평가를 거친 뒤에 합니다. 평가 대신 사용자 불만을 기준으로 내리는 보기는 오답입니다.
