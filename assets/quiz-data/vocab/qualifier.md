말의 범위를 좁히거나 조건을 붙이는 **꾸밈말·단서**입니다. *only*, *high-confidence* 처럼 지시에 덧붙여 "어떤 경우에만"을 정하려는 말이 여기에 해당합니다.

## 문제 속 쓰임
> Adding any **qualifier** to a system prompt increases output length, which expands the set of tokens the evaluator inspects...
> 시스템 프롬프트에 **수식어(한정어)** 를 넣으면 출력이 길어지고, 평가자가 검사할 토큰이 늘어난다.

## 함께 쓰는 표현
- **add a qualifier** : 단서·한정어를 붙이다
- **vague qualifier** : 모호한 한정어
- **without qualification** : 조건 없이, 전면적으로

## 비슷한 말 · 반대말
- **modifier** — 수식어 (문법 용어)
- **caveat** — 단서, 주의 사항

## 시험 포인트
이 보기는 오답입니다. "확신이 높은 것만 보고하라" 같은 한정어가 효과 없는 이유는 출력 길이가 아니라 **무엇을 보고할지 구체적 기준이 없기 때문**입니다. 정답은 모호한 한정어를 **명시적인 범주 기준**으로 바꾸는 것입니다.
