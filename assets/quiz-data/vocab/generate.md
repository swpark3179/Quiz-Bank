없던 것을 **새로 만들어 내는** 것입니다. 모델이 텍스트·코드·요약을 만들어 내는 것을 가리킬 때 가장 흔히 씁니다. 명사는 *generation*(생성)입니다.

## 문제 속 쓰임
> **Generate** a structured handoff summary: issue, verified identifiers, tool results, actions attempted, and recommended next step.
> 문제 내용, 확인된 식별자, 도구 결과, 시도한 조치, 권장 다음 단계를 담은 구조화된 핸드오프 요약을 **생성한다**

## 함께 쓰는 표현
- **generate a summary / report** : 요약·보고서를 만들다
- **generated code / file** : 생성된 코드·파일
- **regenerate** : 다시 생성하다

## 시험 포인트
사람 상담원이 원문 대화를 처음부터 다시 읽어야 한다면, 이슈·확인된 식별자·시도한 조치·권장 다음 단계를 담은 **구조화된 핸드오프 요약**을 만들어 넘기는 보기가 정답입니다.
