상대를 **믿고 맡기는** 것입니다. 보안 맥락의 *trusted* 는 "검증되어 믿을 수 있는", 즉 **내가 통제하는 범위 안에 있는** 기기·사용자·데이터를 가리킵니다.

## 문제 속 쓰임
> Move the server to user-scoped `~/.claude.json` so the token lives only on a single **trusted** machine per engineer.
> 서버를 사용자 스코프인 `~/.claude.json` 으로 옮겨, 토큰이 엔지니어마다 **신뢰할 수 있는** 한 대의 머신에만 있게 한다.

## 함께 쓰는 표현
- **trusted source / machine** : 믿을 수 있는 출처·기기
- **trust boundary** : 신뢰 경계 — 믿을 수 있는 영역과 그렇지 않은 영역의 경계
- **trustworthy** (형) 믿을 만한

## 반대말
- **untrusted** — 신뢰할 수 없는, 검증되지 않은 (사용자 업로드·외부 문서 등)
