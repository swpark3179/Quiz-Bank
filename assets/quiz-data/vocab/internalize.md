배운 것을 겉으로 따라 하는 수준을 넘어 **완전히 자기 것으로 만드는** 것입니다. 모델에 대해 쓰면 학습을 통해 스타일·규칙이 **몸에 배게 한다**는 뜻입니다.

## 문제 속 쓰임
> Fine-tune a model on the team's existing validation code so it **internalizes** the house validation style
> 팀의 기존 검증 코드로 모델을 파인튜닝해, 팀 고유의 검증 스타일을 **내재화하게** 한다

## 함께 쓰는 표현
- **internalize a style / rule** : 스타일 / 규칙을 몸에 익히다
- **internalized** (형) 내재화된

## 시험 포인트
스타일을 "내재화"시키려고 **파인튜닝**하는 보기는 대개 과잉 설계라 오답입니다. 프롬프트에 **구체적인 예시 몇 개**를 넣으면 되는 문제에 비해 비용·운영 부담이 너무 큽니다.
