1. **(위치를) 찾아내다** — 어디 있는지 찾아 정확히 짚어 내는 것. *find* 보다 문서체에 가까운 말
2. **(be located) ~에 있다, 위치하다** — *located in the repo root* 저장소 루트에 있는

## 문제 속 쓰임
> ...Claude must first **locate** every call site across a large monorepo.
> Claude가 먼저 대형 모노레포 전체에서 모든 호출 지점을 **찾아야** 합니다.

## 함께 쓰는 표현
- **locate a file / call site** : 파일 / 호출 지점을 찾아내다
- **location** (명) 위치, 장소

## 시험 포인트
대형 코드베이스에서 대상을 **찾는 탐색**을 메인 세션에서 직접 하면 검색 출력이 컨텍스트를 채웁니다. 탐색은 Explore 서브에이전트에 맡기고 요약만 돌려받는 보기가 정답입니다.
