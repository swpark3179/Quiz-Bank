처리해야 할 **작업의 양과 성격**입니다. "이 작업에 어떤 방식이 맞는가"처럼 시스템이 감당할 일을 통틀어 말합니다.

## 문제 속 쓰임
> What orchestration change best fits this **workload**?
> 이 **작업**에 가장 잘 맞는 오케스트레이션 변경은 무엇일까?

## 함께 쓰는 표현
- **heavy workload** : 많은 작업량
- **batch workload** : 일괄 처리 작업 — Message Batches API 같은 비실시간 처리에 맞음

## 시험 포인트
작업 성격을 먼저 봅니다. 단계가 예측 가능하면 고정 체인, 중간 발견에 따라 계획이 바뀌는 개방형 조사라면 **동적 분해**가 정답입니다.
