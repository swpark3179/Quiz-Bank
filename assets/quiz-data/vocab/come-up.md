## 문제 속 쓰임
> ...but Claude keeps auto-invoking it mid-session whenever dependency files **come up**...
> ...Claude가 세션 도중 의존성 파일 이야기가 **나올** 때마다 이 스킬을 자동으로 호출해...

## 함께 쓰는 표현
- **come up in conversation** : 대화 중에 나오다
- **come up with** ~ : (생각·해결책을) 내놓다 — 뜻이 다르니 주의

## 시험 포인트
관련 주제가 **나올 때마다** 스킬이 자동 호출되는 것을 막고 수동 실행만 남기려면 SKILL.md frontmatter 에 `disable-model-invocation: true` 를 둡니다. description 삭제나 사후 `/compact` 는 오답입니다.
