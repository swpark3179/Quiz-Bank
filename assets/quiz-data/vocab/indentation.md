코드 줄 앞에 공백이나 탭을 넣어 **구조(블록의 깊이)를 드러내는 것**입니다. 탭을 쓸지, 공백 몇 칸을 쓸지는 저장소마다 정하는 대표적인 코딩 규칙입니다.

## 문제 속 쓰임
> Early in a Claude Code session, a developer typed "always use tabs for **indentation** in this repo."
> Claude Code 세션 초반에 개발자가 "이 저장소에서는 항상 탭으로 **들여쓰기**해"라고 입력했습니다.

## 함께 쓰는 표현
- **use tabs for indentation** : 탭으로 들여쓰기하다
- **2-space indentation** : 공백 2칸 들여쓰기
- **indent** (동) 들여 쓰다 · **indented** : 들여 쓴

## 시험 포인트
들여쓰기 규칙처럼 **대화로만 준 지시**는 `/compact` 뒤 요약에 남았을 때만 유지되고, 프로젝트 루트 CLAUDE.md 는 디스크에서 다시 읽혀 재주입됩니다. 계속 지켜야 할 규칙은 CLAUDE.md 에 적는 것이 정답입니다.
