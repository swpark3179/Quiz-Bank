위험을 완전히 없애는 것이 아니라 **일어날 가능성이나 피해를 줄이는** 조치입니다. 보안 문서에서 *mitigations* 는 위협별 대응책 목록을 뜻합니다.

## 문제 속 쓰임
> Which mapping of controls to Anthropic's **mitigation** names is correct?
> 각 통제와 Anthropic이 쓰는 **완화** 기법 이름을 올바르게 짝지은 것은 무엇일까요?

## 함께 쓰는 표현
- **mitigate a risk** : 위험을 줄이다
- **mitigation strategy** : 완화 전략
- **mitigate jailbreaks** : 탈옥을 완화하다

## 비슷한 말 · 반대말
- **prevention** — 예방. 아예 일어나지 않게 막는 것
- **remediation** — 이미 생긴 문제를 바로잡는 것

## 시험 포인트
탈옥·직접 인젝션의 네 완화책은 메인 호출 전 경량 모델 분류 = **무해성 스크린**, 알려진 패턴 대조 = **입력 검증**, 경계·거절 문구 = **프롬프트 엔지니어링**, 같은 사용자의 반복 = **반복 위반자 대응**입니다.
