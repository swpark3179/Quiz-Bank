비어 있는 필드·파일·표에 **값이나 내용을 채워 넣는** 것을 말합니다. 사람이 손으로 쓰기보다 스크립트·시스템이 자동으로 채우는 장면에 자주 씁니다.

## 문제 속 쓰임
> **Populate** each developer's personal `~/.claude/CLAUDE.md` via a one-time onboarding script, which developers can then edit as needed.
> 일회성 온보딩 스크립트로 각 개발자의 개인 `~/.claude/CLAUDE.md` 를 **채우고**, 이후에는 개발자가 필요에 따라 편집하게 한다.

## 함께 쓰는 표현
- **populate a field** : 필드를 채우다
- **populate** A **with** B : A 를 B 로 채우다
- **auto-populated / pre-populated** : 자동으로 / 미리 채워진

## 비슷한 말 · 반대말
- **fill (in)** — 채우다 (일상적인 말)
- **clear / empty** — 비우다

## 시험 포인트
이 보기는 오답입니다. 개인 파일을 한 번 *populate* 해 줘도 개발자가 언제든 고치거나 지울 수 있어 **강제할 수 없습니다.** 모두에게 강제해야 하는 지침은 managed settings 로 배포합니다.
