"**완전히, 아예**"라는 뜻으로, 어떤 일을 부분이 아니라 **통째로** 하거나 하지 않을 때 씁니다.

## 문제 속 쓰임
> Switch tool_choice to "auto" so the model can decline to call the extraction tool **altogether** when the PO number is missing.
> `tool_choice` 를 `"auto"` 로 바꿔, PO 번호가 없을 때 모델이 추출 도구 호출 **자체를** 하지 않을 수 있게 한다

## 함께 쓰는 표현
- **skip ~ altogether** : ~을 아예 건너뛰다
- **avoid ~ altogether** : ~을 아예 피하다

## 비교
- **altogether** — 완전히, 아예
- **all together** — 모두 함께 (띄어 쓰면 뜻이 다름)
