1. **(공간·한도 안에) 들어가다** — *fit in the window* 컨텍스트 창에 다 들어가다
2. **(~에) 맞다, 적합하다** — *best fits* 가장 잘 맞다. 명사로는 *a good fit*(잘 맞는 것)

## 문제 속 쓰임
> Switch to a larger-context model so all of the test output **fits** comfortably in the window, however many runs accumulate.
> 실행이 아무리 쌓여도 모든 테스트 출력이 창에 넉넉히 **들어가도록** 컨텍스트가 더 큰 모델로 바꾼다
> What orchestration change best **fits** this workload?
> 이 작업에 가장 잘 **맞는** 오케스트레이션 변경은 무엇일까요?

## 함께 쓰는 표현
- **fit in / within** ~ : ~ 안에 들어가다
- **best fit / good fit** : 가장 잘 맞는 것 / 잘 맞는 것
- **one-size-fits-all** : 모든 경우를 하나로 맞추는, 획일적인

## 시험 포인트
"더 큰 컨텍스트 창으로 바꿔 **다 들어가게** 한다"는 보기는 대부분 오답입니다. 용량이 아니라 구성의 문제이므로 출력을 **미리 줄이거나 서브에이전트로 격리**하는 쪽이 정답입니다.
