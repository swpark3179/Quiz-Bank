사람이 하던 일을 **프로그램이 알아서 하게 만드는** 것입니다. *automatically* 는 "자동으로", *automation* 은 "자동화"입니다.

## 문제 속 쓰임
> An agentic pipeline **automates** vendor payments.
> 공급업체 대금 지급을 **자동화한** 에이전트 파이프라인
> Subagents inherit the hub's full message history **automatically**
> 서브에이전트는 허브의 전체 메시지 기록을 **자동으로** 상속한다

## 함께 쓰는 표현
- **fully automated** : 완전 자동화된
- **automated tests / checks** : 자동화된 테스트 / 검사

## 시험 포인트
"서브에이전트가 부모 기록을 **자동으로** 상속한다"는 **틀린** 전제입니다. 새로 띄운 서브에이전트는 빈 기록에서 시작하므로 필요한 맥락을 프롬프트로 명시적으로 넘겨야 합니다.
