실제로 수집한 것이 아니라 **인공적으로 만들어 낸** 것을 말합니다. AI 분야에서는 모델이 생성한 질문·대화 같은 *synthetic data* (합성 데이터)를 평가·학습에 쓸 때 자주 나옵니다.

## 문제 속 쓰임
> The team should start with **synthetic** queries generated by Claude, because real usage data is too noisy and unrepresentative at first.
> 처음에는 실제 사용 데이터가 너무 지저분하고 대표성이 없으므로 Claude 가 생성한 **합성** 질의로 시작해야 한다.

## 함께 쓰는 표현
- **synthetic data** : 합성 데이터
- **synthetic queries / test cases** : 만들어 낸 질의·테스트 케이스

## 비슷한 말 · 반대말
- **artificial** — 인공적인
- **real-world** — 실제의 (*real usage data* 실제 사용 데이터)

## 시험 포인트
이 보기는 오답입니다. Anthropic 은 평가를 **실제 사용 패턴을 대표하는 약 20개 질의**로 바로 시작하라고 정리했습니다. "실제 데이터는 지저분하니 합성 질의로 시작"은 근거가 없는 주장입니다.
