어떤 주장·데이터·결과가 **사실인지, 맞는지 확인하는** 과정입니다. 동사는 *verify* 입니다.

## 문제 속 쓰임
> The synthesis agent frequently needs to **verify** specific claims.
> 합성 에이전트는 특정 주장을 자주 **검증해야** 한다.

## 함께 쓰는 표현
- **verify a claim / fact** : 주장 / 사실을 검증하다
- **identity verification** : 본인 확인
- **verified customer ID** : 검증된 고객 ID

## 비교
- **verification** — 사실·사양과 *맞는지* 확인
- **validation** — 형식·요구에 *적합한지* 확인 (예: 입력값 검사)

## 시험 포인트
단순한 사실 확인이 대부분이라면 담당 에이전트에 **범위를 좁힌 검증 도구**를 직접 주고, 복잡한 검증만 기존 경로로 위임하는 방식이 왕복을 줄이면서 신뢰성을 지킵니다.
