거울처럼 **있는 그대로 비추어 담아낸다**는 뜻으로, 결과물이 어떤 사실·의견·변경을 **반영한다**고 할 때 씁니다.

## 문제 속 쓰임
> Average the two figures into a single blended market-size number so the report **reflects** both sources about equally.
> 보고서가 두 출처를 거의 같은 비중으로 **반영하도록**, 두 수치를 평균 내 하나의 혼합 시장 규모 수치로 만든다.

## 함께 쓰는 표현
- **reflect the latest changes** : 최신 변경 사항을 반영하다
- **reflect on** ~ : ~을 되돌아보다, 곰곰이 생각하다
- **reflection** (명) 반영, 성찰

## 시험 포인트
두 수치를 **평균 내서** 둘 다 반영한 척하는 보기는 오답입니다. 서로 다른 시점의 수치라면 출처·발행일 주석과 함께 **둘 다 보존하는** 보기가 정답입니다.
