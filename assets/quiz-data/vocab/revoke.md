한 번 내준 키·토큰·권한을 **무효로 만들어 더는 쓰지 못하게 하는** 것입니다. 유출이 의심되거나 필요 없어진 자격 증명을 끊을 때 씁니다.

## 문제 속 쓰임
> A 401 authentication_error caused by a **revoked** API key
> **폐기된** API 키 때문에 생긴 401 authentication_error

## 함께 쓰는 표현
- **revoke a key / token** : 키·토큰을 폐기하다
- **revoke access** : 접근 권한을 회수하다
- **revocation** (명) : 폐기, 취소

## 비슷한 말 · 반대말
- **rotate** — 키를 새것으로 교체하다
- **grant / issue** — 권한을 주다 / 키를 발급하다

## 시험 포인트
폐기된 키의 401 은 **다시 보내도 해결되지 않으므로** SDK 가 자동 재시도하지 않습니다. SDK 기본 재시도 대상은 연결 오류·408·409·429·500 이상(529 포함) 같은 **일시적 실패**입니다.
