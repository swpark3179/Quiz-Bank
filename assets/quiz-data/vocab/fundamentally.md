겉모습 정도가 아니라 **바탕·원리부터** 다르다는 강조입니다. *fundamentally different* 는 "조금 다른"이 아니라 "**방식 자체가 다른**"이라는 뜻입니다.

## 문제 속 쓰임
> However, the Slack API offers **fundamentally** different integration approaches.
> 그런데 Slack API는 **근본적으로** 다른 통합 방식을 제공한다.

## 함께 쓰는 표현
- **fundamentally different** : 근본적으로 다른
- **fundamentally flawed** : 근본적으로 결함이 있는
- **fundamental** (형) 근본적인, 기본적인

## 시험 포인트
선택지마다 **방식이 근본적으로 다르고** 요구사항까지 모호하다면, 하나를 골라 바로 구현하기보다 plan mode로 트레이드오프를 탐색하고 권고안부터 내는 선택지가 정답 쪽입니다.
