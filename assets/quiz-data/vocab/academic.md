대학·연구 기관의 **학술 연구**와 관련된 것을 말합니다. 검색 도구 문맥에서는 논문·동료 심사 문헌 같은 **학술 자료**를 가리킵니다.

## 문제 속 쓰임
> The web-search subagent is equipped with two tools, search_web and search_academic, each carrying a one-line description ("search the web" / "search **academic** sources").
> 웹 검색 서브에이전트에는 `search_web` 과 `search_academic` 두 도구가 있고, 각각 한 줄짜리 설명("웹 검색" / "**학술** 자료 검색")만 붙어 있습니다.

## 함께 쓰는 표현
- **academic sources / papers** : 학술 자료 / 논문
- **peer-reviewed** : 동료 심사를 거친 (학술 문헌의 특징)

## 시험 포인트
도구 설명이 이렇게 **한 줄뿐이라 서로 비슷하면** 모델이 도구를 잘못 고릅니다. 첫 처방은 입력 형식·예시 쿼리·다루는 출처·사용 경계까지 담아 **설명을 보강하고 차별화**하는 것입니다.
