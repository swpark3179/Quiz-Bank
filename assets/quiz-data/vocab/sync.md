**synchronize** 의 줄임말로, 두 곳의 내용을 **똑같이 맞추는** 것입니다. 저장소·기기 사이에 설정이나 파일을 맞출 때 씁니다.

## 문제 속 쓰임
> Register the conventions in a `.claude/config.json` commands array so that they **sync** with the repository on clone
> 저장소를 클론할 때 함께 **동기화되도록** 규칙을 `.claude/config.json` 의 commands 배열에 등록한다

## 함께 쓰는 표현
- **sync with** ~ : ~와 동기화하다
- **in sync / out of sync** : 맞춰진 / 서로 어긋난

## 비교
- **sync** — (두 곳의 내용을) 같게 맞추다
- **synchronous** — 동기식의, 결과를 기다렸다가 다음으로 넘어가는 (별개 개념)

## 시험 포인트
팀 컨벤션을 클론과 함께 공유하려면 커밋되는 프로젝트 `CLAUDE.md`(또는 `.claude/CLAUDE.md`)에 두는 것이 정답입니다.
