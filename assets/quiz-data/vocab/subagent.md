코디네이터(상위) 에이전트가 일을 나눠 맡기려고 띄우는 **하위 에이전트**입니다. Claude Code·Agent SDK 에서는 `Task` 도구로 생성하며, 각자 **자기만의 깨끗한 컨텍스트**에서 일합니다.

## 문제 속 쓰임
> A multi-agent system has a hub agent that spawns specialist **subagents**.
> 허브 에이전트가 전문 **서브에이전트**들을 생성하는 멀티 에이전트 시스템이 있다.

## 함께 쓰는 표현
- **spawn / delegate to a subagent** : 서브에이전트를 띄우다 / 서브에이전트에 맡기다
- **coordinator (hub) agent** : 서브에이전트를 조율하는 상위 에이전트
- **hub-and-spoke** : 코디네이터를 중심으로 서브에이전트가 연결된 구조

## 시험 포인트
서브에이전트는 부모의 대화 기록을 **물려받지 않습니다**. 필요한 사실·이전 결과는 위임(Task) 프롬프트에 **명시적으로** 넣고, 서브에이전트끼리 직접 부르지 않고 코디네이터를 거치게 하는 것이 정답 패턴입니다.
