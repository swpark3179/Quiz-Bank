본래 하려는 일 외에 **덤으로 더 드는 시간·비용·자원**입니다. 예를 들어 에이전트끼리 결과를 주고받으려고 오가는 왕복 자체가 *overhead* 입니다.

## 문제 속 쓰임
> What's the most effective approach to reduce **overhead** while maintaining reliability?
> 신뢰성을 유지하면서 **오버헤드**를 줄이는 가장 효과적인 방법은?

## 함께 쓰는 표현
- **reduce / add overhead** : 부담을 줄이다 / 늘리다
- **coordination overhead** : 조율에 드는 추가 부담
- **memory / performance overhead** : 메모리 / 성능 부담

## 시험 포인트
오버헤드를 줄이라는 문제에서 **모든 권한을 다 주는** 선택지는 함정입니다. 흔한 단순 작업에만 범위를 좁힌 도구를 주고, 드문 복잡한 작업은 기존 경로를 유지하는 쪽이 정답입니다.
