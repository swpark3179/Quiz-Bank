정해진 틀 없이 **떠오르는 대로 아이디어를 최대한 많이 끌어내는** 것입니다.

## 문제 속 쓰임
> **Brainstorm** and add every conceivable document type to the enum so that no future document falls outside it.
> 생각할 수 있는 모든 문서 유형을 **브레인스토밍해** enum에 추가해서, 앞으로 어떤 문서도 범위 밖으로 벗어나지 않게 한다.

## 함께 쓰는 표현
- **brainstorm ideas / options** : 아이디어·선택지를 떠올려 내다
- **brainstorming session** : 브레인스토밍 회의

## 시험 포인트
enum 에 **가능한 값을 전부 떠올려 넣는** 보기는 오답입니다. 목록 밖의 값이 생길 수 있으면 `"other"` + 상세 문자열 필드를 두는 것이 정답 패턴입니다.
