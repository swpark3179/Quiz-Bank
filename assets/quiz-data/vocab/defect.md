제품·코드가 **제대로 동작하지 못하게 하는 결함**입니다. *bug* 와 거의 같은 뜻이지만 품질 관리·리뷰 문맥에서 더 격식 있게 씁니다.

## 문제 속 쓰임
> ...Claude phrases severe findings differently each run — "severe issue," "major bug," "critical **defect**."
> Claude가 심각한 발견 사항을 실행할 때마다 "severe issue", "major bug", "critical **defect**(치명적 **결함**)"처럼 다르게 표현합니다.
> Enable extended thinking on the generating session before it reviews its own code for **defects**
> 생성 세션이 자기 코드의 **결함**을 리뷰하기 전에 확장 사고(extended thinking)를 켠다

## 함께 쓰는 표현
- **critical defect** : 치명적 결함
- **defect rate** : 결함률
- **defective** (형) 결함이 있는

## 시험 포인트
같은 세션이 만든 코드를 스스로 리뷰하면 결함을 놓칩니다. 사고 깊이를 늘리기보다 **컨텍스트를 공유하지 않는 독립 리뷰 인스턴스**가 정답입니다.
