글 내용이 아니라 **글의 모양·구조를 표시하려고 끼워 넣는 기호**입니다. Markdown 의 `**`·`#`·`-`, HTML 태그 등이 해당하며, 화면에서는 서식으로 바뀌지만 음성으로 읽거나 일반 텍스트로 보면 기호가 그대로 드러납니다.

## 문제 속 쓰임
> Explain why: replies are spoken by an engine that reads formatting symbols aloud, so write plain conversational sentences with no **markup**.
> 이유를 설명한다. 답변은 서식 기호를 소리 내어 읽는 엔진이 음성으로 읽으므로, **마크업** 없는 평범한 대화체 문장으로 쓰라고 한다

## 함께 쓰는 표현
- **no markup** : 서식 기호 없이
- **markup language** : 마크업 언어 (HTML 등)
- **formatting symbols** : 서식 기호

## 비슷한 말 · 반대말
- **plain text** — 서식 없는 일반 텍스트 (반대 개념)
- 가격 문맥에서는 **원가에 붙이는 이윤**(*a 20% markup*)이라는 전혀 다른 뜻도 있습니다

## 시험 포인트
대문자·반복·경고로 규칙을 더 세게 쓰는 것보다 **규칙의 이유를 알려 주는 것**이 정답입니다. 출력이 음성으로 읽힌다는 이유를 알면 Claude 가 금지 목록에 없는 글머리표·제목까지 스스로 피합니다.
