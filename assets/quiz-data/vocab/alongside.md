1. **(위치) ~의 바로 옆에** — 두 대상이 곁에 나란히 붙어 있을 때
2. **~와 함께, 동시에** — 어떤 일을 다른 일과 같이 할 때

## 문제 속 쓰임
> Test files are spread throughout the codebase **alongside** the code they test.
> 테스트 파일은 테스트 대상 코드 **바로 옆에** 놓인 채 코드베이스 곳곳에 흩어져 있다.
> ...automatically calls likely-needed tools **alongside** any requested tool.
> 요청된 도구와 **함께** 필요할 법한 도구까지 자동으로 호출한다.

## 함께 쓰는 표현
- **work alongside** ~ : ~와 나란히 일하다
- **alongside each other** : 서로 나란히

## 비슷한 말
- **next to**, **beside** — 위치상 바로 옆 (함께라는 뜻은 없음)
- **along with**, **together with** — ~와 함께
