1. **(범위에) 걸치다, 아우르다** — 여러 영역·기간에 **넓게 퍼져 있다**는 뜻입니다 (*tools spanning billing and CRM* 결제와 CRM 에 걸친 도구)
2. **구간, 범위** — 어느 지점부터 어느 지점까지의 한 덩어리 (*time span* 기간). 마크다운의 *code span* 은 백틱으로 감싼 인라인 코드 구간입니다

## 문제 속 쓰임
> ...and (c) with 45 tools **spanning** billing, CRM, and infrastructure, it often picks the wrong tool.
> ...(c) 결제·CRM·인프라에 **걸친** 도구 45개 중에서 엉뚱한 도구를 자주 고릅니다.

> ...and @config/legacy.json wrapped in backticks as a Markdown code **span**.
> ...다른 하나는 마크다운 코드 **스팬**으로 백틱에 감싼 @config/legacy.json 입니다.

## 함께 쓰는 표현
- **span multiple** ~ : 여러 ~에 걸치다
- **code span** : 인라인 코드 구간
- **time span** : 기간

## 시험 포인트
도구가 여러 영역에 *spanning* 해 선택이 흔들리면 영역별로 도구를 좁힌 **전문화** 서브에이전트가 해결책입니다. CLAUDE.md 의 `@` 가져오기는 **코드 스팬 안에서는 해석되지 않고** 글자 그대로 남습니다.
