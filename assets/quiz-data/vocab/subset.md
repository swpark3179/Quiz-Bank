전체 중에서 **일부만 골라낸 묶음** 입니다. 수학에서는 '부분집합'이고, 일반 문맥에서는 "~ 가운데 일부"라는 뜻으로 씁니다.

## 문제 속 쓰임
> Implement a routing classifier that enables only the **subset** of tools appropriate for each request type.
> 요청 유형마다 알맞은 도구 **일부**만 활성화하는 라우팅 분류기를 구현한다.

## 함께 쓰는 표현
- **a subset of ~** : ~의 일부
- **a small / large subset** : 일부 소수 / 상당 부분

## 비슷한 말 · 반대말
- **portion**, **part** — 일부 (집합의 느낌은 약함)
- **superset** — 상위 집합, 더 큰 전체 (반대)

## 시험 포인트
도구의 **일부만 노출**하는 방법은 "어떤 도구를 쓸 수 있느냐"를 제한할 뿐, 호출 *순서*를 강제하지는 못합니다. 순서를 반드시 지켜야 한다면 프로그램으로 강제하는 전제조건이 필요합니다.
