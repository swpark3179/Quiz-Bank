계획·설계·방안을 **실제로 만들어 돌아가게 하는** 것입니다. 코드로 기능을 *구현하다*는 뜻도 되고, 전략·정책을 *적용·도입하다*는 뜻도 됩니다.

## 문제 속 쓰임
> **Implement** PreToolCall hooks that flag and reject tool calls made in direct response to retrieved document content...
> 검색·업로드된 문서 내용에 직접 반응해 이뤄진 도구 호출을 표시·거부하는 PreToolCall 훅을 **구현한다**
> ...the cumulative message history exceeds the effective attention range; **implement** a summarization/compaction strategy
> 누적 대화 기록이 실질적인 주의 범위를 넘었다. 요약/압축(compaction) 전략을 **구현한다**

## 함께 쓰는 표현
- **implement a hook / strategy** : 훅을 구현하다 / 전략을 적용하다
- **implementation** (명) 구현, 구현체 · **implementation details** : 구현 세부 사항

## 비슷한 말
- **build** — 만들다 (더 일반적)
- **apply**, **adopt** — (방법을) 적용하다, 도입하다
