같은 일을 **되풀이하는** 것입니다. 부사 *repeatedly* 는 "여러 번 거듭해서".

## 문제 속 쓰임
> In a long debugging session Claude **repeatedly** runs the full test suite; each run dumps roughly 2,000 lines of passing-test noise into the context.
> 긴 디버깅 세션에서 Claude가 전체 테스트 스위트를 **반복해서** 실행하는데, 실행할 때마다 통과한 테스트에 관한 소음이 약 2,000줄씩 컨텍스트에 쌓인다.

## 함께 쓰는 표현
- **repeated tool calls** : 반복된 도구 호출
- **repeat the same mistake** : 같은 실수를 되풀이하다
- **repetition** (명) 반복

## 시험 포인트
반복 실행으로 쌓인 장황한 출력 때문에 중요한 정보를 놓친다면 **쌓이기 전에 필요한 줄만 남기고 핵심 제약은 앞쪽 요약에 고정하는** 보기가 정답입니다. 더 큰 창이나 `/compact` 반복은 오답입니다.
