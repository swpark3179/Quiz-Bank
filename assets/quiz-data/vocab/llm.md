**Large Language Model** 의 줄임말로, 방대한 텍스트로 학습해 글을 이해하고 만들어 내는 **대규모 언어 모델**입니다. Claude 도 LLM 입니다.

## 문제 속 쓰임
> ...코드로 한 번 정의하면 되는 결정적 변환에 **LLM** 호출을 쓰는 과잉 설계입니다.

## 함께 쓰는 표현
- **LLM call** : 모델 호출 — 비용·지연이 들고 결과가 확률적
- **LLM-as-a-judge** : 모델이 다른 모델의 출력을 채점하게 하는 방식

## 시험 포인트
코드로 정확히 처리할 수 있는 **결정적 변환**(형식 변환·정규화 등)에 LLM 호출을 쓰는 보기는 확률적이고 비용만 늘리는 **과잉 설계**라 오답입니다.
