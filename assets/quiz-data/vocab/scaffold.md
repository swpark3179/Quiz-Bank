공사장의 비계(발판)에서 온 말로, 코드에서는 세부 구현 전에 **파일·클래스 같은 기본 뼈대를 먼저 만들어 두는** 것을 뜻합니다.

## 문제 속 쓰임
> Start direct execution to **scaffold** the Slack channel class, deferring the integration method decision until later.
> 바로 실행에 들어가 Slack 채널 클래스의 **뼈대를 먼저 만들고**, 통합 방식 결정은 나중으로 미룬다.

## 함께 쓰는 표현
- **scaffold a project / component** : 프로젝트·컴포넌트의 기본 구조를 만들다
- **scaffolding** (명) 뼈대 코드; (공사장의) 비계

## 비슷한 말
- **boilerplate** — 매번 거의 그대로 반복해 쓰는 상용구 코드
- **skeleton** — 내용 없이 구조만 갖춘 코드

## 시험 포인트
핵심 설계 결정이 정해지지 않았는데 **뼈대부터 만드는** 선택지는 잘못된 추상화 위에 작업할 위험이 있어 오답이 되기 쉽습니다. 요구사항이 모호하면 먼저 plan mode 로 선택지를 살피는 쪽이 낫습니다.
