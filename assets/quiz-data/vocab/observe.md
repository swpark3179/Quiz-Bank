1. **(보고) 알아차리다** — *you observe that ~* 은 "~라는 것을 발견하다"
2. **지켜보다, 관찰하다** — 진행되는 일을 계속 볼 수 있다

## 문제 속 쓰임
> ...you **observe** that the web search agent and document analysis agent are both investigating the same subtopics.
> 웹 검색 에이전트와 문서 분석 에이전트가 같은 하위 주제를 둘 다 조사하고 있음을 **알게 된다**.
> The coordinator can **observe** all interactions, handle errors consistently, and decide what information each subagent should receive
> 코디네이터는 모든 상호작용을 **지켜보고**, 오류를 일관되게 처리하며, 각 서브에이전트가 받을 정보를 정할 수 있다.

## 함께 쓰는 표현
- **observation** (명) 관찰, 관찰 결과
- **observability** (명) 관찰 가능성 — 로그·지표로 시스템 내부 상태를 볼 수 있는 정도

## 시험 포인트
모든 통신을 코디네이터로 거치게 하는 구조의 핵심 이점은 **모든 상호작용을 지켜볼 수 있다**는 점입니다. 즉 중앙 가시성, 일관된 오류 처리, 정보 흐름 통제입니다.
