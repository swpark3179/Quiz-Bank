1. **(A를 B에) 대응시키다, 매핑하다** — 한쪽 항목을 다른 쪽 항목과 짝지어 연결하는 것. 명사 *mapping* 은 "대응 관계, 짝지은 표"
2. **지도 / (구조를) 파악하다** — *map the codebase* 코드베이스 구조를 훑어 파악하다

## 문제 속 쓰임
> Preserve claim-to-source **mappings** through synthesis so each claim carries its originating sources into report generation.
> 종합 단계를 거치는 동안 주장과 출처의 **매핑을** 보존해, 각 주장이 원래 출처를 달고 보고서 생성 단계까지 가게 한다

## 함께 쓰는 표현
- **map A to B** : A를 B에 대응시키다
- **mapping pass** : 전체 구조를 먼저 훑어 파악하는 단계
- **model tier mapping** : 작업별로 모델 등급을 짝지은 것
