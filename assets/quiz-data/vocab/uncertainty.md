결과나 판단을 **확신할 수 없는 상태** 입니다. 에이전트 문제에서는 "정보는 다 모았지만 어떻게 처리해야 할지 확실하지 않은" 상황에 자주 나옵니다.

## 문제 속 쓰임
> After calling `get_customer` and `lookup_order`, the agent has all available system data but faces **uncertainty**.
> `get_customer` 와 `lookup_order` 를 호출한 뒤 에이전트는 시스템 데이터를 모두 가졌지만 **불확실성**에 부딪힌다.

## 함께 쓰는 표현
- **face / reduce uncertainty** : 불확실성에 부딪히다 / 불확실성을 줄이다
- **under uncertainty** : 불확실한 상황에서
- **uncertain** (형) 불확실한 — *uncertain flags* 확신이 낮은 지적

## 반대말
- **certainty**, **confidence** — 확실성, 확신

## 시험 포인트
불확실성은 숨기지 말고 **드러내어 전달**하는 쪽이 정답 방향입니다. 일부 소스가 빠졌다면 어떤 결론이 잘 뒷받침되고 어디에 공백이 있는지 표시해 넘깁니다.
