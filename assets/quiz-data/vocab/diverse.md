여러 종류가 **고루 섞여 서로 다른** 상태를 말합니다. 퓨샷 예시에서는 길이·언어·결말 등이 한쪽으로 쏠리지 않고 실제 입력의 폭을 덮는다는 뜻으로 씁니다.

## 문제 속 쓰임
> (a) relevant, (b) **diverse**, (c) structured with tags
> (a) 관련성, (b) **다양성**, (c) 태그를 이용한 구조화

## 함께 쓰는 표현
- **diverse examples** : 다양한 예시
- **a diverse set of** ~ : 여러 종류가 섞인 ~ 묶음
- **diversity** : 다양성

## 비슷한 말 · 반대말
- **varied** — 여러 가지의 (거의 같은 뜻)
- **uniform** — 획일적인, 한결같은

## 시험 포인트
예시들이 **우연히 같은 점**(모두 할인 제안으로 끝남)을 공유해 모델이 그대로 따라 하면 *diverse* 가 답입니다. 실제 입력과 동떨어진 것은 *relevant*, 예시 속 문장을 지시로 읽는 것은 태그 구조화 문제입니다.
