## 문제 속 쓰임
> The agent sometimes selects `get_customer` when `lookup_order` would be more appropriate, **particularly** for ambiguous requests.
> 에이전트가 **특히** 모호한 요청에서 `lookup_order` 가 더 적절한데도 `get_customer` 를 고르기도 한다.

## 함께 쓰는 표현
- **particularly when / for** ~ : 특히 ~일 때 / ~에서
- **not particularly** ~ : 별로 ~하지 않은
- **particular** (형) 특정한 · **in particular** 특히

## 비슷한 말
- **especially** — 거의 같은 뜻, 조금 더 일상적
- **specifically** — "구체적으로 말하면"; 강조보다 범위를 좁히는 느낌
