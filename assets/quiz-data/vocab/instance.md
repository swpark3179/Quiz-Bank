## 문제 속 쓰임
> Run the review in a separate, independent Claude Code **instance** that shares no context with the generating session
> 생성 세션과 컨텍스트를 전혀 공유하지 않는 별도의 독립 Claude Code **인스턴스**에서 리뷰를 실행한다

## 함께 쓰는 표현
- **separate / independent instance** : 별도의 / 독립 인스턴스
- **for instance** : 예를 들어 (= *for example*)

## 시험 포인트
코드나 테스트를 만든 세션은 자기 결과물에 편향됩니다. **컨텍스트를 공유하지 않는 독립 인스턴스**가 리뷰하게 하는 보기가 정답입니다.
