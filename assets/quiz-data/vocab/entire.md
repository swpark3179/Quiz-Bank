빠짐없이 **전체, 온** ~ 이라는 뜻입니다. 부사 *entirely* 는 "완전히, 아예".

## 문제 속 쓰임
> ...human agents report they must re-read the **entire** raw conversation to understand each case...
> 사람 상담원들은 각 건을 파악하려고 원본 대화 **전체**를 다시 읽어야 한다고 말한다
> ...the agent occasionally calls the wrong tool and sometimes misses tool calls **entirely**.
> 에이전트가 가끔 엉뚱한 도구를 호출하고, 도구 호출을 **아예** 놓치기도 한다.

## 함께 쓰는 표현
- **the entire codebase / conversation** : 코드베이스·대화 전체
- **entirely different** : 완전히 다른

## 시험 포인트
에스컬레이션할 때 사람이 **대화 전체를 다시 읽게** 만드는 것은 오답의 신호입니다. 고객 정보·문제·시도한 조치·남은 일을 담은 **구조화된 요약**을 함께 넘기는 보기가 정답입니다.
