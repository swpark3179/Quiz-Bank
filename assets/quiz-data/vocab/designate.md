어떤 대상을 특정 역할·용도로 **정식으로 지정해 두는** 것입니다. *designated* ~ 는 "지정된, 전용의 ~"라는 뜻입니다.

## 문제 속 쓰임
> Set a forced tool_choice so the subagent always uses one **designated** search tool regardless of the query's topic or type.
> 쿼리의 주제나 유형과 관계없이 서브에이전트가 **지정된** 검색 도구 하나만 항상 쓰도록 강제 `tool_choice` 를 설정한다.

## 함께 쓰는 표현
- **designated reviewer / owner** : 지정된 리뷰어·담당자
- **designate A as B** : A를 B로 지정하다
- **designation** (명) 지정, 명칭

## 시험 포인트
쿼리 성격에 따라 도구를 골라야 하는데 **지정 도구 하나를 강제**하면 선택이 오히려 틀어집니다. 도구 오선택에는 **도구 설명 보강**이 첫 단계입니다.
