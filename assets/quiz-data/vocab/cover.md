"덮다"에서 나와, 어떤 대상·범위를 **빠짐없이 다루다, 포함하다**라는 뜻으로 많이 씁니다. 테스트·도구·문서가 무엇까지 "커버하는지" 말할 때 씁니다.

## 문제 속 쓰임
> Consolidate the two tools into one unified search tool whose single description **covers** both general web pages and academic sources.
> 두 도구를 일반 웹 페이지와 학술 출처를 모두 **다루는** 설명 하나짜리 통합 검색 도구로 합친다

## 함께 쓰는 표현
- **cover a case / scenario** : 경우·시나리오를 다루다 (*already covered* 이미 다룬)
- **covering every type** : 모든 유형을 아우르는
- **coverage** (명) 다루는 범위, 커버리지

## 시험 포인트
도구를 잘못 고를 때 첫 처방은 도구를 합치는 것이 아니라, 각 도구 설명에 **입력 형식·예시 쿼리·다루는 출처 범위·경계**를 보강하는 것입니다.
