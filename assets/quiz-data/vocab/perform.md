맡은 작업·동작을 **실제로 해내는** 것입니다. *do* 보다 격식 있는 말이라 단계·검사·리뷰 같은 명사와 잘 어울립니다.

## 문제 속 쓰임
> ...the same Claude Code session that generates an implementation also **performs** the automated review step.
> 구현을 생성한 바로 그 Claude Code 세션이 자동 리뷰 단계까지 **수행한다**.

## 함께 쓰는 표현
- **perform a check / review / search** : 검사·리뷰·검색을 수행하다
- **performance** (명) 성능, 수행

## 시험 포인트
같은 세션이 만들고 스스로 리뷰하면 자기 결과물을 늘 통과시킵니다. **컨텍스트를 공유하지 않는 독립 리뷰 인스턴스**가 정답입니다.
