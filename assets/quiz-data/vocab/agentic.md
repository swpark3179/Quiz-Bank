모델이 한 번 답하고 끝나는 게 아니라 **스스로 도구를 고르고 결과를 보며 여러 단계를 이어 가는** 방식을 말합니다.

## 문제 속 쓰임
> An engineer builds an **agentic** customer support bot.
> 엔지니어가 **에이전트형** 고객지원 봇을 만들었다.

## 함께 쓰는 표현
- **agentic loop** : 에이전트 루프 — 모델 호출 → 도구 실행 → 결과 전달을 반복하는 흐름
- **agentic pipeline / workflow** : 에이전트형 파이프라인 / 워크플로

## 시험 포인트
에이전트 루프의 계속·종료는 모델이 쓴 문장이 아니라 **`stop_reason`** 으로 판단합니다(`tool_use` → 도구 실행 후 계속, `end_turn` → 종료). 폭주를 막는 **최대 반복 횟수** 같은 안전장치도 함께 둡니다.
