흩어진 것을 **한곳에 모은다**는 말입니다. 에이전트 문제에서는 검색·조회로 자료나 정보를 수집하는 단계(*gather context*)를 가리킵니다.

## 문제 속 쓰임
> Give the synthesis subagent web search tools so it can **gather** the material it needs
> 종합 서브에이전트에 웹 검색 도구를 줘 필요한 자료를 스스로 **모으게** 한다.

## 함께 쓰는 표현
- **gather context** : 맥락을 모으다
- **gather sources** : 출처를 수집하다
- **information gathering** : 정보 수집

## 비슷한 말 · 반대말
- **collect** — 모으다 (거의 같은 뜻)
- **scatter** — 흩뜨리다

## 시험 포인트
서브에이전트는 코디네이터의 대화를 보지 못하므로, 앞 단계가 이미 *gather* 한 결과는 **코디네이터가 스폰 프롬프트에 직접 넣어야** 전달됩니다. 검색 도구를 줘서 다시 모으게 하면 작업만 중복되어 오답입니다.
