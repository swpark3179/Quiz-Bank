2. **관행, 실무 방식** — *best practice* 는 "모범 사례"

## 문제 속 쓰임
> **In practice** the agent almost always reaches for the built-in Grep tool instead...
> 그런데 **실제로** 에이전트는 거의 항상 내장 `Grep` 도구를 쓴다.

## 함께 쓰는 표현
- **in practice** : 실제로는
- **best practice** : 모범 사례, 권장 방식
- **common practice** : 흔한 관행

## 시험 포인트
