손대지 않은 **원본 그대로의 상태**를 말합니다. 데이터에서는 요약·정리·변환을 거치지 않은 출력·기록을, *raw JSON* 처럼 쓰면 다른 것이 섞이지 않은 "순수한" JSON 을 뜻합니다.

## 문제 속 쓰임
> ...human agents report they must re-read the entire **raw** conversation to understand each case...
> 사람 상담원들은 각 건을 파악하려고 **원본** 대화 전체를 다시 읽어야 한다고 말한다.

## 함께 쓰는 표현
- **raw output / data** : 가공하지 않은 출력 / 원본 데이터
- **raw transcript** : 정리 안 된 대화 기록 전체
- **raw JSON** : 마크다운·설명 없이 JSON 만 있는 것

## 시험 포인트
원본을 그대로 넘기는 보기(대화 전체 첨부, 원본 출력을 그대로 다음 단계로)는 대개 오답입니다. 사람에게는 **구조화된 핸드오프 요약**, 다음 에이전트에게는 **추려 다듬은 결과**를 넘기는 것이 정답 방향입니다.
