## 문제 속 쓰임
> More **detailed** system prompt with payment validation instructions
> 지급 검증 지침을 담은 더 **상세한** 시스템 프롬프트
> The tool descriptions are: 'Gets user information' and 'Fetches account **details**'.
> 도구 설명은 각각 "Gets user information"(사용자 정보 조회), "Fetches account details"(계정 **세부 정보** 조회)입니다.

## 함께 쓰는 표현
- **in detail** : 자세히
- **error details** : 오류 상세 정보
- **detail field** : 추가 설명을 담는 필드 (*document_type_detail*)

## 시험 포인트
"더 **상세한** 시스템 프롬프트"는 오답 보기의 단골입니다. 고위험 작업은 프롬프트를 늘리는 것이 아니라 **사람 확인 게이트·훅 같은 구조적 통제**로 막습니다.
