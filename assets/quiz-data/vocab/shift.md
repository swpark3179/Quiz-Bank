1. **(서서히) 옮기다, 바꾸다** — 위치·비중·방향을 한쪽에서 다른 쪽으로 조금씩 넘긴다 (*shift traffic* 트래픽을 옮기다)
2. **전환, 변화** — 방식이나 관점이 바뀌는 것 (*a shift in approach*)
3. **교대 근무** — 일하는 조가 바뀌는 근무 단위 (*the end of a shift* 교대가 끝날 때)

## 문제 속 쓰임
> **Shift** traffic from the old version to the new one gradually, keeping both running side by side.
> 기존 버전과 새 버전을 함께 실행해 두고, 트래픽을 새 버전으로 점진적으로 **옮긴다**.

> An SRE keeps pasting the same 12-step on-call handoff procedure into Claude Code at the end of every **shift**.
> 한 SRE 가 **교대**가 끝날 때마다 똑같은 12단계 온콜 인수인계 절차를 Claude Code 에 붙여 넣습니다.

## 함께 쓰는 표현
- **shift from A to B** : A 에서 B 로 옮기다
- **gradual shift** : 점진적 전환
- **night shift** : 야간 근무

## 시험 포인트
장시간 실행되는 에이전트의 배포 문제에서 *shift traffic gradually* 는 옛 버전과 새 버전을 나란히 돌리며 조금씩 옮기는 **레인보우 배포**를 뜻하고, 이것이 정답입니다.
