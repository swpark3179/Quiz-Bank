## 문제 속 쓰임
> Increase the context window so that both the old and the new search results can **coexist** in one session
> 이전 검색 결과와 새 검색 결과가 한 세션 안에 **함께 있을** 수 있도록 컨텍스트 창을 늘린다

## 함께 쓰는 표현
- **coexist with** ~ : ~와 공존하다
- **coexistence** (명) 공존

## 시험 포인트
낡은 결과와 새 결과를 한 컨텍스트에 **같이 두면** 어느 쪽이 최신인지 혼동만 커집니다. 이전 도구 결과가 낡았다면 새 세션 + 이전 결론 요약 주입 + 재조회가 정답입니다.
