시간이 지나 **더 이상 최신이 아닌, 낡은** 정보를 가리킵니다. 원래 빵 같은 음식이 "오래되어 굳은"이라는 뜻입니다.

## 문제 속 쓰임
> Fork the prior session so the **stale** results are copied into a new branch that continues the report
> 이전 세션을 포크해, **낡은** 결과가 복사된 새 분기에서 보고서 작성을 이어 간다

## 함께 쓰는 표현
- **stale data / cache** : 오래된 데이터 / 캐시
- **stale tool results** : 낡은 도구 결과
- **go stale** : 낡아지다, 최신성을 잃다

## 반대말
- **fresh**, **up-to-date** — 새로운, 최신의

## 시험 포인트
낡은 도구 결과가 문제일 때 `--resume`, fork, `/compact` 는 그 결과를 **그대로 끌고 갑니다**. **새 세션 + 이전 결론 요약 + 다시 조회**가 정답 패턴입니다.
