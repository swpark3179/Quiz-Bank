**standard input** 의 줄임말로, 프로그램이 실행될 때 **입력을 받아 읽는 기본 통로**입니다. 셸에서 `|`(파이프)나 `<` 로 넘긴 데이터가 여기로 들어옵니다.

## 문제 속 쓰임
> 훅은 파일 경로를 환경 변수가 아니라 **stdin** JSON의 `tool_input.file_path` 로 받습니다.

## 함께 쓰는 표현
- **read from stdin** : 표준 입력에서 읽다
- **pipe into stdin** : (다른 명령의 출력을) 표준 입력으로 넘기다

## 비교
- **stdin** — 입력 / **stdout** — 정상 출력 / **stderr** — 오류 메시지 출력

## 시험 포인트
Claude Code 훅 스크립트는 이벤트 정보(도구 이름, `tool_input` 등)를 **stdin 으로 들어오는 JSON** 으로 받습니다. 환경 변수로 받는다고 가정한 설명은 의심하세요.
