1. **(이야기·작업의) 흐름, 맥락** — 실 한 가닥처럼 이어지는 줄기. *lose the thread* 는 "흐름을 놓치다"
2. **스레드** — 게시판·메신저의 대화 묶음, 또는 프로그램의 실행 단위

## 문제 속 쓰임
> What should the developer do to keep going without losing the **thread**?
> **맥락**을 잃지 않고 작업을 이어 가기 위해 개발자가 해야 할 일은 무엇일까요?

## 함께 쓰는 표현
- **lose the thread** : 흐름·맥락을 놓치다
- **pick up the thread** : (끊긴) 흐름을 다시 잇다
- **thread-safe** : 여러 스레드가 동시에 써도 안전한
