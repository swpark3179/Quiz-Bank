계획하지 않았는데 **도중에 (문제·상황과) 맞닥뜨리는** 것입니다. 오류·장애물처럼 반갑지 않은 대상과 함께 자주 씁니다.

## 문제 속 쓰임
> The document analysis subagent **encounters** a corrupted PDF file it cannot parse.
> 문서 분석 서브에이전트가 파싱할 수 없는 손상된 PDF 파일을 **만났다**.

## 함께 쓰는 표현
- **encounter an error / a problem** : 오류·문제에 부딪히다
- **encounter unexpected complexity** : 예상치 못한 복잡성을 만나다

## 비슷한 말
- **run into**, **come across** — 더 일상적인 표현
- **face** — (어려움에) 직면하다

## 시험 포인트
"일단 직접 실행하고 복잡성을 **만나면** 그때 plan mode 로 바꾼다"는 보기는, 이미 큰 변경을 한 뒤에야 문제를 발견하게 되어 오답입니다.
