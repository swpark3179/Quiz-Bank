관련된 것을 **빠짐없이 넓게 다 담는** 것입니다. 다만 시험 선택지에서는 "포괄적으로 다 넣는다"가 **해법이 아닌 경우**가 많으니 주의합니다.

## 문제 속 쓰임
> Use direct execution with **comprehensive** upfront instructions detailing exactly how each service should be structured.
> 각 서비스를 어떻게 구성할지 정확히 적은 **포괄적인** 사전 지침을 주고 바로 실행한다.

## 함께 쓰는 표현
- **comprehensive error handling** : 빠짐없는 에러 처리
- **comprehensive security audit** : 종합 보안 감사
- **comprehensively** (부) 포괄적으로

## 시험 포인트
"**comprehensive** 지침·문서·테스트를 더 넣는다"는 선택지는 그럴듯하지만, 근본 원인(탐색 부족·좁은 작업 분해·확증 편향 등)을 건드리지 않아 **오답인 경우가 많습니다**.

## 비교
- **comprehensive** — 포괄적인, 빠짐없는
- **comprehensible** — 이해할 수 있는
