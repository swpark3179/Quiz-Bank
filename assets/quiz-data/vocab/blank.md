1. **비어 있는** — 값이나 내용이 채워지지 않은 상태입니다 (*leave ~ blank* ~을 비워 두다)
2. **빈칸** — 채워 넣어야 할 자리입니다 (*fill in the blank* 빈칸을 채우다)

## 문제 속 쓰임
> On one submission, the employee left the project code **blank** on the physical form, so it does not appear anywhere in the scanned image.
> 한 제출 건에서 직원이 종이 양식의 프로젝트 코드 칸을 **비워 두어**, 스캔 이미지 어디에도 코드가 없다.

> Which event name fills the **blank**?
> **빈칸**에 들어갈 이벤트 이름은 무엇인가?

## 함께 쓰는 표현
- **leave blank** : 비워 두다
- **fill in the blank** : 빈칸을 채우다

## 시험 포인트
원본 양식이 *blank* 라 값이 아예 없는 실패는 재시도·더 엄격한 스키마·고해상도 스캔·더 큰 모델로 풀리지 않습니다. **재시도를 멈추고 사람 검토자에게 넘기는** 보기가 정답입니다.
