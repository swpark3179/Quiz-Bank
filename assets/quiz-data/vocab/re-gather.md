*re-*(다시) + *gather*(모으다)로, 이미 한 번 모았던 정보를 **직접 다시 찾아 모으는** 것입니다.

## 문제 속 쓰임
> Give the synthesis subagent its own web-search tool so it can **re-gather** the missing figures and named sources itself
> 합성 서브에이전트에 자체 웹 검색 도구를 주어, 빠진 수치와 출처를 직접 **다시 수집하게** 한다.

## 함께 쓰는 표현
- **gather information / evidence** : 정보·근거를 모으다
- **re-fetch** : (같은 자료를) 다시 가져오다

## 시험 포인트
서브에이전트 결과에 앞 단계 정보가 빠졌다면, 도구를 더 줘서 **다시 모으게 하는** 보기는 중복 작업이라 오답입니다. 코디네이터가 **위임 프롬프트에 앞선 발견 사항을 그대로 넣어 주는** 보기가 정답입니다.
