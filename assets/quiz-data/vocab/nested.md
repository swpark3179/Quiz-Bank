어떤 구조 **안에 같은 종류의 구조가 또 들어 있는** 것입니다. JSON 객체 안의 객체, 폴더 안의 폴더처럼 *계층*이 생기는 경우에 씁니다.

## 문제 속 쓰임
> ...some fields are **nested** differently and timestamps aren't formatted correctly.
> 일부 필드는 **중첩** 방식이 다르고, 타임스탬프 형식도 맞지 않는다.

## 함께 쓰는 표현
- **nested object / field** : 중첩된 객체·필드
- **deeply nested** : 여러 겹으로 깊이 중첩된
- **nesting** (명) 중첩 · **nesting rules** : 중첩 규칙

## 반대말
- **flat** — 중첩 없이 한 층으로 펼쳐진 (*flat structure*)
