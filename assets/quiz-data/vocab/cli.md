**Command-Line Interface(명령줄 인터페이스)** 의 줄임말입니다. 화면 버튼 대신 터미널에 **명령어와 옵션(플래그)을 입력**해 쓰는 방식으로, `claude` 명령도 CLI 입니다.

## 해설 속 쓰임
> ...도구를 모델에게서 아예 빼는 것은 `disallowedTools`(**CLI**에서는 `--tools`, `--disallowedTools`)입니다.

## 함께 쓰는 표현
- **CLI flag / option** : 명령줄 옵션 (`--` 로 시작)
- **CLI tool** : 명령줄 도구

## 비교
- **CLI** — 명령어로 조작 · **GUI** — 화면(그래픽)으로 조작
