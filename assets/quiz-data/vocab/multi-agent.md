*multi-*(여럿) + *agent* 로, **여러 에이전트가 역할을 나눠 함께 일하는** 구조를 가리킵니다. 보통 코디네이터(허브)가 전문 서브에이전트에게 작업을 나눠 줍니다.

## 문제 속 쓰임
> A **multi-agent** system has a hub agent that spawns specialist subagents.
> 허브 에이전트가 전문 서브에이전트들을 생성하는 **멀티 에이전트** 시스템이 있습니다.

## 함께 쓰는 표현
- **multi-agent system / orchestration** : 멀티 에이전트 시스템 / 조율
- **hub-and-spoke** : 허브 앤 스포크 — 모든 통신이 코디네이터를 거치는 구조
- **single-agent** : (대비) 단일 에이전트

## 시험 포인트
서브에이전트는 **허브의 대화 기록을 상속하지 않고 빈 기록으로 시작**합니다. 필요한 맥락·발견 사항은 위임 프롬프트에 **명시적으로** 넣어야 한다는 점이 자주 정답이 됩니다.
