1. **(감정·사실을) 인정하다, 알아주다** — 상대의 불만이나 상황을 "그럴 만하다"고 받아 주는 것입니다. 상대 말에 동의한다는 뜻까지는 아닙니다
2. **(받았음을) 확인해 주다** — 메시지·요청을 잘 받았다고 알리는 것입니다 (*acknowledge receipt*)

## 문제 속 쓰임
> So the agent **acknowledged** the frustration and offered a human as an option.
> 그래서 에이전트는 고객의 불편을 **인정하고** 상담원 연결을 선택지로 제안했다.

## 함께 쓰는 표현
- **acknowledge the frustration** : 불만(답답함)을 알아주다
- **acknowledge receipt** : 수신을 확인하다
- **acknowledgment** : 인정, 수신 확인

## 시험 포인트
고객 지원 문항에서 *acknowledge* 는 **감정을 알아주되 그것만으로 사람에게 넘기지는 않는다**는 신호입니다. 처리 범위 안의 요청이면 "인정 → 직접 해결 → 상담원 연결은 선택지로 제안"이 정답이고, 고객이 사람을 명시적으로 다시 요청하면 그때는 조사 없이 바로 넘깁니다.
