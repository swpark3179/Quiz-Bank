처음과 끝 **사이에 끼어 있는** 단계나 결과물을 말합니다. 파이프라인에서는 최종 결과가 아닌 *중간 산출물*이나 *중간 단계*를 가리킵니다.

## 문제 속 쓰임
> Add an **intermediate** summarization agent that condenses findings before passing to synthesis
> 결과를 합성 단계로 넘기기 전에 압축하는 **중간** 요약 에이전트를 추가한다.

## 함께 쓰는 표현
- **intermediate step / stage** : 중간 단계
- **intermediate results** : 중간 결과
- **intermediate commits** : 처음과 마지막 사이의 중간 커밋

## 시험 포인트
**중간 단계(에이전트)를 하나 더 끼워 넣는** 선택지는 호출·비용·실패 지점을 늘리고 정보도 잃기 쉽습니다. 원인이 상류의 장황한 출력이라면 그 원천을 고치는 쪽이 정답입니다.
