조건에 맞을 수도 있어 **살펴볼 대상으로 추린 것(후보)** 입니다. 문제에서는 수정이 필요할지도 모르는 **후보 파일**을 말합니다.

## 문제 속 쓰임
> Read every **candidate** file into the main session first so all call sites are visible before any edit begins, then plan the rename.
> 편집을 시작하기 전에 모든 호출 지점이 보이도록 **후보** 파일을 전부 메인 세션에 먼저 읽어 들인 뒤, 이름 변경을 계획한다.

## 함께 쓰는 표현
- **candidate files / solutions** : 후보 파일 / 해결책
- **a good candidate for** ~ : ~에 알맞은 대상

## 시험 포인트
후보 파일을 **메인 세션에 전부 읽어 들이는** 보기는 컨텍스트를 오염시키는 오답입니다. 탐색은 Explore 서브에이전트에 맡기고 요약만 돌려받는 것이 정답입니다.
