시기상 **무엇보다 먼저 존재했다**는 뜻입니다. *pre-*(앞) + *date*(날짜)로 생각하면 쉽습니다.

## 문제 속 쓰임
> Include git blame data so Claude can identify comments that **predate** recent code modifications
> git blame 데이터를 넣어 Claude가 최근 코드 수정보다 **먼저 작성된** 주석을 찾게 한다.

## 비슷한 말 · 반대말
- **precede**, **come before** — ~보다 앞서다 (시간·순서 모두)
- **postdate**, **follow** — ~보다 뒤에 오다

## 시험 포인트
주석이 **언제** 쓰였는지(git blame)는 그 주석이 **맞는지**와 무관합니다. 오래된 주석도 옳을 수 있으므로, "주석이 말하는 동작이 실제 코드와 모순될 때만 표시하라"처럼 기준을 명확히 하는 쪽이 근본 해결입니다.
