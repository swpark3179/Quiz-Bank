전부가 아니라 **필요한 것만 골라서** 하는 것을 뜻합니다. 부사 *selectively* 는 "선별적으로, 골라서"입니다.

## 문제 속 쓰임
> ...since Batch API jobs are atomic and cannot be reprocessed partially or **selectively**.
> Batch API 작업은 원자적이라 **일부만 골라** 재처리할 수 없으므로

## 함께 쓰는 표현
- **selectively load / apply** : 골라서 불러오다 / 적용하다
- **be selective about** ~ : ~을 신중히 고르다

## 시험 포인트
배치 결과는 `custom_id` 로 건별 매칭이 되므로 실패한 요청만 **골라서 다시 처리할 수 있습니다**. "선택적으로 재처리할 수 없다"는 전제가 붙은 보기는 오답입니다.
