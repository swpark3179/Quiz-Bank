1. **(시스템·대상에) 닿다, 접근하다** — *reach backend systems* 백엔드 시스템에 접근하다
2. **(수치·목표·결론에) 이르다** — *reach a conclusion*, *reach a limit*
3. **reach for** ~ — (습관처럼) ~부터 집어 쓰다, ~에 손을 뻗다

## 문제 속 쓰임
> A customer support resolution agent built with the Claude Agent SDK **reaches** backend systems through custom MCP tools...
> Claude Agent SDK로 만든 고객 지원 해결 에이전트가 커스텀 MCP 도구로 백엔드 시스템에 **접근한다**.

## 함께 쓰는 표현
- **reach a conclusion** : 결론에 이르다
- **reach the context limit** : 컨텍스트 한도에 다다르다
- **reach for a tool** : (어떤) 도구부터 집어 쓰다 — *reaches for the built-in Grep tool*
