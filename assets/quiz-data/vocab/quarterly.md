1년을 넷으로 나눈 **3개월(분기)마다**의 뜻입니다. 기업 실적·보고서 이야기에 자주 나옵니다.

## 문제 속 쓰임
> ...requests to "analyze the **quarterly** report I uploaded" are routed to the web search agent.
> "내가 업로드한 **분기** 보고서를 분석해 줘"라는 요청이 웹 검색 에이전트로 보내진다.

## 함께 쓰는 표현
- **quarterly report / earnings** : 분기 보고서 / 분기 실적
- **quarter** (명) 분기 · **Q1~Q4** 1~4분기
- **on a quarterly basis** : 분기마다

## 비슷한 말
- **monthly** 매월 · **annual / yearly** 매년 · **weekly** 매주 · **nightly** 매일 밤
