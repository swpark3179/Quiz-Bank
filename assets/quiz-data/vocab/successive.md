같은 종류의 것이 **하나 끝나면 다음 것이 오는 식으로 줄지어 이어지는** 모습입니다. 순서대로 이어진다는 점이 핵심이라 *successive turns* 는 "한 대화 안에서 차례로 이어지는 턴"이 됩니다.

## 문제 속 쓰임
> Run the per-file passes as **successive** turns in one conversation, so later passes can draw on what earlier files showed
> 파일별 패스를 한 대화의 **연이은** 턴으로 돌려, 뒤의 패스가 앞 파일에서 알게 된 것을 활용하게 한다.

## 함께 쓰는 표현
- **successive turns** : 연이은 턴
- **successive attempts** : 잇따른 시도
- **successive versions** : 잇따른 버전들

## 비슷한 말
- **consecutive** — 연속된 (사이에 끊김이 없다는 점을 더 강조)
- **sequential** — 순차적인

## 시험 포인트
이 보기는 오답입니다. 300개 파일을 한 대화의 연이은 턴으로 리뷰하면 컨텍스트가 쌓여 주의가 흐려집니다. 정답은 파일마다 **새 컨텍스트**의 로컬 패스를 돌린 뒤, 데이터를 공유하는 파일을 함께 읽는 **통합 패스**를 더하는 것입니다.
