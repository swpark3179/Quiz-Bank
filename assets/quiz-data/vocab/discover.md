몰랐던 것을 **찾아내다, 알아내다** 라는 뜻입니다. 문제에서는 미리 정해 두지 않고 **탐색해서 실제로 찾아낸** 대상을 가리킵니다.

## 문제 속 쓰임
> Run a mapping pass enumerating the repository's real modules, then dynamically spawn one subagent per **discovered** component
> 저장소의 실제 모듈을 열거하는 매핑 단계를 먼저 실행한 뒤, **발견된** 구성 요소마다 서브에이전트를 하나씩 동적으로 생성한다

## 함께 쓰는 표현
- **discover that** ~ : ~라는 사실을 알아내다
- **discovery** (명) 발견, 탐색 단계
- **rediscover** : (이미 찾은 것을) 다시 찾다 — 맥락이 전달되지 않았다는 신호

## 비슷한 말
- **find out** — 알아내다 (일상적인 말)
- **uncover** — 숨겨진 것을 밝혀내다
