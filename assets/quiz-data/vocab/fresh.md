1. **(이전 기록 없이) 새로운, 깨끗한** — *fresh session* 이전 대화 기록이 없는 새 세션
2. **방금 얻은, 최신의** — *fresh results* 방금 다시 가져온 결과

## 문제 속 쓰임
> Run each of the three changes in its own **fresh** session so every edit stays cleanly isolated from the others
> 세 변경을 각각 **새** 세션에서 실행해, 모든 수정이 서로 깔끔하게 격리되도록 한다

## 함께 쓰는 표현
- **start fresh** : 처음부터 새로 시작하다
- **fresh session / context** : 새 세션 / 깨끗한 컨텍스트
- **fresh data** : 최신 데이터

## 시험 포인트
**새 세션**은 코드가 바뀌어 이전 도구 결과가 낡았을 때, 이전 결론 요약을 주입해 다시 시작하는 용도로 정답이 됩니다. 반대로 서로 얽힌 변경을 각각 새 세션에서 따로 처리하는 보기는 오답이고, **한 메시지로 묶는** 것이 정답입니다.
