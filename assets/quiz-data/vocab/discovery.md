무언가를 **찾아내는 과정**입니다. 코딩 에이전트 문제에서는 편집에 들어가기 전에 호출 지점·관련 파일을 **찾아 모으는 탐색 단계**를 뜻합니다.

## 문제 속 쓰임
> Doing this **discovery** inline reads dozens of files and floods the main session with search output before any edits begin...
> 이 **탐색**을 메인 세션에서 직접 하면 편집을 시작하기도 전에 수십 개 파일을 읽어 메인 세션이 검색 출력으로 넘쳐난다.

## 함께 쓰는 표현
- **discovery phase** : 탐색 단계
- **do discovery inline** : 탐색을 메인 흐름 안에서 바로 하다
- **discover** (동) 찾아내다

## 시험 포인트
장황한 탐색을 메인 세션에서 하면 컨텍스트가 넘쳐 뒤의 편집이 흔들립니다. 탐색은 **Explore 같은 서브에이전트에 맡기고 요약만 돌려받는** 보기가 정답입니다.
