1. **심볼** — 코드에서 함수·클래스·변수처럼 **이름이 붙은 요소** (*symbol search* 심볼 검색)
2. **기호** — `$`, `#` 같은 표시

## 문제 속 쓰임
> The team added a code-intelligence MCP server that does semantic, cross-file **symbol** search over an indexed monorepo.
> 팀이 인덱싱된 모노레포에서 의미 기반의 파일 간 **심볼** 검색을 하는 코드 인텔리전스 MCP 서버를 추가했다.

## 함께 쓰는 표현
- **symbol search / lookup** : 심볼 검색 / 조회
- **go to symbol** : (에디터에서) 해당 정의로 이동

## 시험 포인트
좋은 MCP 도구가 있는데도 에이전트가 내장 `Grep` 만 쓴다면, 첫 단계는 **도구 설명 보강**(무엇을 하는지, 언제 `Grep` 보다 나은지, 예시 쿼리)입니다.
