## 문제 속 쓰임
> During a 200-file **framework** migration carried out in one long session, logs show Claude re-migrating files it already converted...
> 하나의 긴 세션에서 파일 200개 규모의 **프레임워크** 마이그레이션을 진행하는 동안, Claude가 이미 변환한 파일을 다시 마이그레이션하는 모습이 로그에 나타난다.

## 함께 쓰는 표현
- **framework migration** : 프레임워크 이전(교체)
- **testing framework** : 테스트 프레임워크
