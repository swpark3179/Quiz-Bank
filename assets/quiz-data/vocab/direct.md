1. **직접의, 바로 ~하는** — 중간 단계 없이 곧바로. 부사 *directly* 는 "직접, 곧바로"
2. **(동) 지시하다, (~로) 향하게 하다** — *direct the agent to* ~ : 에이전트에게 ~하라고 지시하다

## 문제 속 쓰임
> ...flag and reject tool calls made in **direct** response to retrieved document content without user confirmation
> 검색·업로드된 문서 내용에 **직접 반응해** 이뤄진 도구 호출을 사용자 확인 없이는 표시·거부한다
> A team commits a `CLAUDE.md` file with: 'Never commit **directly** to main branch'.
> 팀이 "main 브랜치에 **직접** 커밋하지 마라"는 내용의 `CLAUDE.md` 를 커밋했다.

## 함께 쓰는 표현
- **in direct response to** ~ : ~에 곧바로 반응해
- **commit directly to main** : (PR 없이) main 에 바로 커밋하다
- **direct access** : 직접 접근

## 시험 포인트
`CLAUDE.md` 의 "직접 커밋하지 마라" 같은 문장은 **지침**일 뿐 강제 장치가 아닙니다. 반드시 막아야 하는 동작이라면 hook·권한 설정 같은 **결정적(deterministic) 수단**이 필요합니다.
