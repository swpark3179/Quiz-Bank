어떤 일을 해도 된다고 **당사자가 허락하는 것**입니다. 보안·개인정보 문맥에서는 도구 실행이나 데이터 접근 전에 **사용자가 명시적으로 승인**하는 절차를 가리킵니다.

## 문제 속 쓰임
> (a) creates and manages the connections and enforces user **consent** and security policy; ...
> (a) 연결을 만들고 관리하며 사용자 **동의**와 보안 정책을 집행한다...

## 함께 쓰는 표현
- **user consent** : 사용자 동의
- **consent to** ~ : ~에 동의하다
- **without consent** : 동의 없이

## 비슷한 말 · 반대말
- **approval / permission** — 승인 / 허가

## 시험 포인트
MCP에서 연결을 만들고 관리하며 사용자 *consent* 와 보안 정책을 집행하는 것은 **호스트**입니다. 클라이언트는 정확히 한 서버와 연결을 유지하고, 서버는 도구·리소스·프롬프트를 노출합니다.
