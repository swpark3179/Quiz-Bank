추상적인 설명이 아니라 **실제 사례·수치로 손에 잡히게** 만든 것입니다. 프롬프트 문제에서는 "말로 규칙을 설명하기"와 대비되는 **"실제 예시를 보여 주기"** 를 가리킵니다.

## 문제 속 쓰임
> Provide 2-3 **concrete** input-output examples showing the expected transformation for representative API responses.
> 대표적인 API 응답에 대해 기대하는 변환을 보여 주는 **구체적인** 입력-출력 예시 2~3개를 제공한다.

## 함께 쓰는 표현
- **concrete example** : 구체적인 예시
- **concretely** (부) 구체적으로

## 반대말
- **abstract** — 추상적인
- **vague** — 모호한, 막연한

## 시험 포인트
산문 지침을 다듬어도 결과가 들쭉날쭉할 때는 **concrete 예시**를 주는 선택지가 정답으로 자주 나옵니다. 예시가 기대 결과를 모호함 없이 보여 주기 때문입니다.
