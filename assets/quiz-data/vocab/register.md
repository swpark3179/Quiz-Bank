시스템이 알아볼 수 있게 목록·설정에 **올려 두는(등록하는)** 것입니다. 명사 *registration* 은 "등록", *registry* 는 "등록된 목록(레지스트리)".

## 문제 속 쓰임
> The subagents were **registered** at user scope while the coordinator runs at project scope, so it cannot see them
> 서브에이전트는 user 스코프에 **등록되었는데** 코디네이터는 project 스코프에서 실행되어, 코디네이터가 서브에이전트를 볼 수 없다.

## 함께 쓰는 표현
- **register a tool / hook** : 도구·훅을 등록하다
- **registration** (명) 등록

## 시험 포인트
코디네이터가 위임을 **아예 시도하지 않는다면** 등록 스코프보다 `allowedTools` 에 **Task 도구가 빠졌는지**를 먼저 봅니다. 위 보기는 그 문제의 오답이었습니다.
