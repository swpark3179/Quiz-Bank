텍스트를 모델이 읽고 쓰는 단위인 **토큰으로 잘게 쪼개는 장치·규칙**입니다. 토큰은 단어 하나일 수도, 단어의 일부나 글자일 수도 있어서 단어 수·글자 수와 토큰 수가 일대일로 맞지 않습니다. 쪼개는 과정은 *tokenization* 이라 합니다.

## 문제 속 쓰임
> About 2,300 tokens, because Claude's **tokenizer** maps exactly one token to each English word.
> 약 2,300토큰. Claude 의 **토크나이저**는 영어 단어 하나를 정확히 토큰 하나로 대응시키기 때문이다.

## 함께 쓰는 표현
- **token counting** : 토큰 수 세기 (정확한 값은 토큰 카운팅 API 로)
- **new tokenizer** : 새 토크나이저 — 같은 텍스트라도 토큰 수가 달라짐
- **tokenization** : 토큰화

## 시험 포인트
이 보기는 오답입니다. 단어와 토큰은 일대일이 아닙니다. Sonnet 4.6 같은 이전 모델은 **영문 약 3.5자 = 1토큰**으로 어림하고, Opus 4.7 이후 모델의 새 토크나이저는 같은 텍스트에서 약 30% 더 많은 토큰을 만듭니다. 확정할 때는 대상 모델로 토큰을 셉니다.
