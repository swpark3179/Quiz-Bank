말로 설명하는 대신 **실제 예를 보여 줘서 알게 하는** 것입니다. 프롬프트 문맥에서는 few-shot 예시가 원하는 동작을 *보여 준다*는 뜻으로 자주 씁니다.

## 문제 속 쓰임
> Add few-shot examples to the system prompt **demonstrating** correct tool selection (5-8 examples).
> 올바른 도구 선택을 **보여 주는** few-shot 예시 5~8개를 시스템 프롬프트에 추가한다.

## 함께 쓰는 표현
- **examples demonstrating** ~ : ~을 보여 주는 예시
- **demonstrate that** ~ : ~임을 입증하다
- **demonstration** (명) 시연, 입증 · **demo** 줄임말

## 시험 포인트
"few-shot 예시로 보여 준다"는 보기는 정답일 때도 오답일 때도 있습니다. 도구 설명이 빈약하거나 순서를 **강제**해야 하는 문제라면 근본 조치가 먼저이고, 예시를 쓴다면 **모호한 경우와 판단 이유**를 보여 주는 쪽이 정답입니다.
