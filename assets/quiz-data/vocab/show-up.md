안 보이던 것이 **겉으로 드러나다, 나타나다**는 뜻의 구동사입니다. 사람에게는 "(약속 장소에) 나타나다", 데이터·결과에는 "(목록·로그·출력에) 보이다, 잡히다"로 씁니다.

## 문제 속 쓰임
> Skip the sweep and start converting files directly, so the usage patterns **show up** as Claude works through the codebase
> 탐색을 건너뛰고 바로 파일 변환을 시작해, Claude 가 코드베이스를 처리하는 동안 사용 패턴이 **드러나게** 한다.

## 함께 쓰는 표현
- **show up in** ~ : ~에 나타나다 (*show up in the logs* 로그에 찍히다)
- **stop showing up** : 더 이상 나오지 않게 되다
- **show up as** ~ : ~로 표시되다

## 비슷한 말
- **appear** — 나타나다 (더 격식 있는 말)
- **turn up** — (뜻밖에) 나타나다, 발견되다

## 시험 포인트
이 보기는 오답입니다. 사전 탐색 없이 작업하며 패턴이 *저절로 드러나길* 기다리면 파일마다 변환 방식이 달라져 재작업이 생깁니다. 정답은 탐색을 **Explore 서브에이전트**에 맡기고 요약만 받는 것입니다.
