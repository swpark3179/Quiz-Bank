위아래 단계가 있는 **계층 구조**입니다. 코드에서는 부모 클래스와 자식 클래스가 이어진 상속 구조(*class hierarchy*)를, Claude Code에서는 여러 위치의 `CLAUDE.md` 가 겹겹이 쌓여 적용되는 구조를 가리킵니다.

## 문제 속 쓰임
> Raise the session's maximum output token limit, so the agent can lay out each class **hierarchy** in full before answering questions.
> 세션의 최대 출력 토큰 한도를 올려, 답하기 전에 각 클래스 **계층**을 전부 펼쳐 쓸 수 있게 한다.

## 함께 쓰는 표현
- **class hierarchy** : 클래스 상속 구조
- **CLAUDE.md hierarchy** : 여러 단계에 놓인 `CLAUDE.md` 묶음
- **hierarchical** : 계층적인

## 시험 포인트
긴 세션에서 앞서 찾은 클래스 *hierarchy* 를 잊고 일반론으로 답하는 것은 출력 한도 문제가 아니라 **컨텍스트 희석**입니다. 발견한 클래스·상위 클래스를 노트 파일에 적고 답하기 전에 읽게 하는 것이 정답입니다.
