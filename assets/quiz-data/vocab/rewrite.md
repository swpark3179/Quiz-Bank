이미 있는 글·코드를 **새로 고쳐 쓰는** 것입니다. 조금 손보는 *edit* 보다 범위가 크고, 같은 내용을 다른 형식으로 다시 쓰는 경우도 포함합니다. 활용은 *rewrite – rewrote – rewritten* 입니다.

## 문제 속 쓰임
> **Rewrite** descriptions to explicitly state when to call each tool and what data each returns — include the entity type and use case
> 각 도구를 *언제* 호출해야 하는지, *어떤 데이터*를 반환하는지 명시하도록 설명을 **다시 쓴다** — 엔티티 유형과 사용 사례 포함

## 함께 쓰는 표현
- **rewrite A from scratch** : A를 처음부터 다시 쓰다
- **a full rewrite** : 전면 재작성

## 비교
- **edit**, **revise** — 부분적으로 고치다
- **rewrite** — 크게, 또는 통째로 다시 쓰다

## 시험 포인트
모델이 비슷한 도구를 헷갈려 잘못 고를 때 가장 먼저 할 일은 **도구 설명(description)을 다시 쓰는 것**입니다 — 언제 쓰는지, 무엇을 돌려주는지, 비슷한 도구와 어떻게 다른지를 적습니다.
