함수·도구·스킬 등을 **불러서 실행시키는** 것입니다. *call* 과 거의 같은 뜻이지만 조금 더 격식 있는 말이며, 명사형 *invocation* (호출)도 자주 나옵니다.

## 문제 속 쓰임
> Create a skill that references the exemplar endpoints and includes pattern-following instructions, **invoked** on-demand via slash command.
> 예시 엔드포인트를 참조하고 패턴 준수 지침을 담은 스킬을 만들어, 슬래시 커맨드로 필요할 때 **호출한다**.

## 함께 쓰는 표현
- **invoke a tool / skill / function** : 도구·스킬·함수를 호출하다
- **invocation** (명) 호출 · **re-invoke** (동) 다시 호출하다

## 비슷한 말
- **call** — 가장 일반적인 말
- **trigger** — 조건이나 이벤트가 실행을 일으키다
