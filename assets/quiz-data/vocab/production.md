**실제 사용자가 쓰는 운영 환경**입니다. 개발·테스트 환경과 달리 여기서 생긴 문제는 실제 고객과 비용에 바로 영향을 줍니다.

## 문제 속 쓰임
> **In production**, the agent occasionally calls the wrong tool and sometimes misses tool calls entirely.
> **운영 환경에서** 에이전트가 가끔 엉뚱한 도구를 호출하고, 도구 호출을 아예 놓치기도 한다.

## 함께 쓰는 표현
- **in production** : 운영 중에, 실서비스에서
- **production logs** : 운영 로그
- **production-ready** : 실서비스에 내보낼 수 있는

## 비교
- **staging** — 운영 직전 검증 환경
- **development** — 개발 환경
