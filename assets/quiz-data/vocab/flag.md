1. **(문제로) 표시하다, 짚어 두다** — 리뷰·검사에서 문제가 있다고 표시한다. 명사로는 그렇게 **표시된 지적 항목**
2. **(명령줄) 플래그, 옵션** — `-p` 처럼 명령 뒤에 붙여 동작을 바꾸는 스위치

## 문제 속 쓰임
> Add the `-p` **flag**: `claude -p "Analyze this pull request for security issues"`
> `-p` **플래그**를 추가한다: `claude -p "..."`
> Configure Claude to only surface findings it assesses as high confidence, filtering out uncertain **flags**.
> Claude가 신뢰도가 높다고 판단한 발견만 보여 주고, 불확실한 **지적 항목**은 걸러 내도록 설정한다.

## 함께 쓰는 표현
- **flag A as B** : A를 B로 표시하다 (*flag a pattern as problematic*)
- **flag an issue / a discrepancy** : 문제·불일치를 짚어 표시하다
- **red flag** : 위험 신호
