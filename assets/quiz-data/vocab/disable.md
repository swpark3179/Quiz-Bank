켜져 있던 기능을 **끄다, 쓰지 못하게 하다** 라는 뜻입니다.

## 문제 속 쓰임
> **Disable** Grep and instead Read each candidate file directly in the main session, one service after another
> `Grep` 을 **끄고**, 대신 메인 세션에서 후보 파일을 서비스별로 하나씩 직접 `Read` 한다

## 함께 쓰는 표현
- **disable a feature / tool** : 기능·도구를 끄다
- **disabled** (형) 비활성화된
- **`disable-model-invocation: true`** : (스킬 frontmatter) Claude가 스스로 호출하지 않고 `/이름` 으로만 실행되게 하는 설정

## 반대말
- **enable** — (기능을) 켜다

## 시험 포인트
문제가 생긴 기능을 **통째로 꺼 버리는** 보기(*Disable PDF upload*)는 필요한 기능까지 잃기 때문에 대개 오답입니다. 기능은 그대로 두고 원인을 막는 쪽이 정답입니다.
