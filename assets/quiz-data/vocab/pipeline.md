여러 처리 단계를 **차례로 이어, 앞 단계의 출력이 다음 단계의 입력이 되게** 만든 흐름입니다. CI/CD·데이터 처리·에이전트 워크플로에서 두루 씁니다.

## 문제 속 쓰임
> An agentic **pipeline** automates vendor payments.
> 공급업체 대금 지급을 자동화한 에이전트 **파이프라인**.

## 함께 쓰는 표현
- **agentic pipeline** : 에이전트가 단계를 처리하는 파이프라인
- **CI pipeline** : 지속적 통합 파이프라인
- **downstream / upstream** : (파이프라인의) 뒤 단계 / 앞 단계
