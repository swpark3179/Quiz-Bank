*mis*(잘못) + *use*(쓰다)로, **원래 용도와 다르게 잘못 쓰는** 것입니다. 실수로 그러면 '오용', 일부러 그러면 '악용'이 됩니다. 코드 리뷰에서는 값이 잘못 쓰이는 버그, 보안에서는 권한 악용을 가리킵니다.

## 문제 속 쓰임
> You need a review that catches local bugs and also bugs where a value is **misused** after it crosses a file boundary.
> 파일 내부의 버그와, 값이 파일 경계를 넘은 뒤 **잘못 쓰이는** 버그를 모두 잡는 리뷰가 필요합니다.

## 함께 쓰는 표현
- **misuse of** ~ : ~의 오용·악용
- **stop misuse** : 악용을 막다

## 비슷한 말 · 반대말
- **abuse** — 남용, 악용 (더 강하고 의도적인 말)
- **misapply** — 잘못 적용하다

## 시험 포인트
값이 파일 경계를 넘은 뒤 잘못 쓰이는 버그는 파일별 패스만으로 보이지 않아, **새 컨텍스트의 파일별 패스 + 파일 간 통합 패스**가 정답입니다. 넓은 관리자 권한을 주고 훅으로 오용을 막겠다는 보기는 최소 권한 원칙에 어긋나 오답입니다.
