예나 그림을 들어 **어떤 원리·사실을 분명하게 보여 준다**는 말입니다. 시험 질문의 *What does this best illustrate?* 는 "이 사례가 가장 잘 보여 주는 원리는 무엇인가?"라는 뜻입니다.

## 문제 속 쓰임
> What does this best **illustrate** about JSON schema enforcement via tool use?
> 이것은 도구 사용을 통한 JSON 스키마 강제에 대해 무엇을 가장 잘 **보여 주는가**?

## 함께 쓰는 표현
- **best illustrate** : 가장 잘 보여 주다
- **illustrate with an example** : 예를 들어 설명하다
- **illustration** : 예시, 삽화

## 비슷한 말 · 반대말
- **demonstrate** — (증거로) 입증해 보이다
- **show** — 보여 주다 (일반적인 말)

## 시험 포인트
*illustrate* 질문은 사례 뒤의 **일반 원리**를 고르게 합니다. 이 문항에서는 "스키마 검증은 필드의 존재·타입만 보장하고, 값이 원문과 맞는지는 보장하지 못한다"가 그 원리입니다.
