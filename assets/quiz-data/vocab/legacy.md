오래전에 만들어져 **지금도 쓰이지만 바꾸기 어려운** 기존 시스템·코드를 말합니다. 문서가 부족하고 구조를 아는 사람이 적다는 뉘앙스가 따라옵니다.

## 문제 속 쓰임
> A coordinator agent is asked to produce a migration plan for a 400,000-line **legacy** billing monolith.
> 코디네이터 에이전트에게 40만 줄짜리 **레거시** 청구(billing) 모놀리스의 마이그레이션 계획을 만들라는 요청이 들어왔다.

## 함께 쓰는 표현
- **legacy system / code** : 레거시 시스템 / 코드
- **legacy schema** : 오래된 데이터베이스 스키마

## 시험 포인트
*legacy* 는 "실제 구조를 **미리 알 수 없다**"는 신호입니다. 고정 분할 대신 먼저 탐색해 구조를 파악하거나, 거의 바뀌지 않는 스키마라면 **MCP 리소스로 한 번 노출**해 반복 탐색을 없애는 보기가 정답입니다.
