1. **(분명히) 밝히다, 명시하다** — 글·규정에 또렷하게 적어 둔다는 느낌. *Policy states that…* 는 "정책에 ~라고 되어 있다"
2. **상태** — 어떤 시점의 값·상황 (*file state*, *session state*)

## 문제 속 쓰임
> Rewrite descriptions to explicitly **state** when to call each tool and what data each returns
> 각 도구를 언제 호출해야 하는지, 어떤 데이터를 반환하는지 **명시하도록** 설명을 다시 쓴다
> Company policy **states** that any refund above $500 must be approved by a manager rather than auto-issued.
> 회사 정책에 **따르면** $500 초과 환불은 자동으로 지급하지 않고 반드시 관리자 승인을 받아야 한다.

## 함께 쓰는 표현
- **stated** (형) 명시된 — *the stated total* 적혀 있는 총액
- **statement** (명) 진술, 명세 / (코드의) 문(文)
- **stateless / stateful** : 상태를 저장하지 않는 / 저장하는
