## 문제 속 쓰임
> A multi-agent system has a hub agent that spawns **specialist** subagents.
> 허브 에이전트가 **전문** 서브에이전트들을 생성하는 멀티 에이전트 시스템이 있습니다.

## 함께 쓰는 표현
- **specialist subagent** : 특정 작업 전담 서브에이전트
- **domain specialist** : 도메인 전문가

## 반대말
- **generalist** — 여러 일을 두루 하는 쪽

## 시험 포인트
허브 앤 스포크 구조에서는 코디네이터가 일을 나눠 맡기고, 각 전문 서브에이전트는 **자기 역할에 필요한 도구만** 가집니다.
