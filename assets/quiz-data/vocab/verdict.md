검토 끝에 내린 **최종 판정·결론**입니다. 원래는 재판의 "평결"이고, 코드 리뷰·평가에서는 "통과 / 지적" 같은 판정 결과를 말합니다.

## 문제 속 쓰임
> Write an exhaustive list in CLAUDE.md of every code pattern and the correct **verdict** for each one
> CLAUDE.md에 모든 코드 패턴과 각각의 올바른 **판정**을 망라한 목록을 작성한다

## 함께 쓰는 표현
- **reach a verdict** : 판정을 내리다
- **take a majority vote on the verdict** : 판정을 다수결로 정하다

## 시험 포인트
모호한 사례에서 판정이 들쭉날쭉할 때 모든 경우를 나열하는 목록은 오답입니다. **판정 이유를 담은 대표 few-shot 예시 2~4개**가 정답입니다.
