어떤 원인 때문에 생기는 **결과, 영향, 효과**입니다. 문제에서는 특정 현상의 이름(*lost-in-the-middle effect*)에 붙어 나옵니다.

## 문제 속 쓰임
> Done inline, this verbose discovery floods the main session's context and later steps degrade from lost-in-the-middle **effects**.
> 이 장황한 탐색을 메인 세션 안에서 바로 하면 메인 세션의 컨텍스트가 넘쳐나고, 이후 단계는 lost-in-the-middle **효과**로 품질이 떨어진다.

## 함께 쓰는 표현
- **side effect** : 부작용, (도구 호출이 일으키는) 외부 변경
- **have an effect on** ~ : ~에 영향을 주다
- **take effect** : 효력이 생기다, 적용되다

## 비교
- **effect** (명) 영향·결과 / **affect** (동) 영향을 주다

## 시험 포인트
*lost-in-the-middle* 은 긴 입력의 **가운데 정보를 놓치기 쉬운** 현상입니다. 핵심 정보는 앞·뒤에 두고, 장황한 출력은 서브에이전트로 격리해 컨텍스트를 줄이는 보기가 정답 쪽입니다.
