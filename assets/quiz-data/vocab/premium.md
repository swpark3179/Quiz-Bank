기본보다 **웃돈을 더 얹은** 값이나, 그만큼 **한 단계 높은 등급**을 말합니다. 가격 문제에서는 "더 비싸게 내고 무언가를 더 얻는다"는 신호입니다.

## 문제 속 쓰임
> It raises output tokens per second on supported Opus models at **premium** prices; it does not mainly cut time to first token...
> 지원되는 Opus 모델에서 **할증된(프리미엄)** 가격으로 초당 출력 토큰을 높인다. 첫 토큰까지의 시간을 주로 줄이는 것은 아니다.

## 함께 쓰는 표현
- **premium price / pricing** : 할증 가격
- **at a premium** : 웃돈을 주고
- **premium tier** : 상위 등급·요금제

## 비슷한 말 · 반대말
- **surcharge** — 추가 요금 (비슷한 뜻)
- **discount** — 할인 (예: 배치의 50% 할인)

## 시험 포인트
fast mode 는 **같은 모델·초당 출력 토큰 증가·프리미엄 가격·Opus 일부만·배치 불가**로 판별합니다. "fast mode 가 더 싸다"거나 "비용을 줄이려고 fast mode 를 쓴다"는 보기는 오답입니다.
