시스템·모델·사람이 **어떻게 움직이는지(동작하는 방식)** 를 말합니다. 영국식 철자는 *behaviour*, 동사는 *behave* 입니다.

## 문제 속 쓰임
> ...because it cannot tell from the single tool which **behavior** it is invoking.
> 하나의 도구만으로는 자신이 어떤 **동작**을 호출하는지 구분하지 못해...
> What is the correct **behavior**?
> 올바른 **동작**은 무엇일까요?

## 함께 쓰는 표현
- **expected behavior** : 기대 동작
- **change behavior** : 동작을 바꾸다 (*cleanups that change behavior*)
- **behavioral** (형) 동작·행동의

## 시험 포인트
한 도구가 **서로 다른 동작**(전액 환불 / 부분 크레딧)을 뭉뚱그리면 오용이 생깁니다. 도구를 나누고 각 description 에 언제 쓰는지 경계를 적는 것이 정답입니다.
