접두사 *re-*(다시) + *describe*(설명하다)로, 이미 한 설명을 **처음부터 다시 해 주는** 것입니다.

## 문제 속 쓰임
> Start a brand-new session with no prior context and **re-describe** the entire task, accepting the loss of current file state.
> 이전 컨텍스트가 전혀 없는 완전히 새로운 세션을 시작해 작업 전체를 **다시 설명하고**, 현재 파일 상태에 대한 맥락을 잃는 것을 감수한다.

## 함께 쓰는 표현
- **re-describe the task** : 작업을 다시 설명하다
- **re-explain** : 다시 설명하다 (비슷한 말)

## 시험 포인트
같은 작업을 이어 가는데 기록만 부풀었다면 새 세션에서 다시 설명하기보다 **`/compact`** 가 정답입니다. 이전 결과가 낡았거나 작업이 바뀌었을 때만 새 세션(+이전 결론 요약)을 고릅니다.
