주고받은 말·메시지를 **처음부터 끝까지 그대로 적은 기록**입니다. 요약본과 달리 아무것도 줄이지 않은 원문입니다.

## 문제 속 쓰임
> Attach the full untrimmed **transcript** of the conversation so the human agent has every message available to read.
> 사람 상담원이 모든 메시지를 읽을 수 있도록, 잘라 내지 않은 **대화 전체 기록**을 첨부한다

## 함께 쓰는 표현
- **full transcript** : 전체 대화 기록
- **session transcript** : 세션 기록

## 비교
- **transcript** — 원문 그대로의 전체 기록
- **summary** — 핵심만 줄인 요약

## 시험 포인트
사람에게 넘길 때 원문 전체를 붙이면 상담원이 다시 다 읽어야 해 처리 시간이 늘어납니다. **구조화된 핸드오프 요약**이 정답입니다.
