비슷한 정도가 아니라 **차이가 하나도 없이 똑같은** 것입니다. *similar* (비슷한)보다 훨씬 강한 말입니다.

## 문제 속 쓰임
> ...flagging a pattern as problematic in one file while approving **identical** code elsewhere in the same PR.
> 한 파일에서는 어떤 패턴을 문제로 표시하면서, 같은 PR의 다른 곳에 있는 **동일한** 코드는 승인한다.

## 함께 쓰는 표현
- **identical to** ~ : ~와 똑같은
- **nearly / virtually identical** : 거의 똑같은
- **identically** (부) 똑같이

## 비교
- **similar** — 비슷하지만 차이가 있을 수 있다
- **identical** — 완전히 같다

## 시험 포인트
같은 PR 안에서 **똑같은 코드**에 서로 다른 판정이 나온다면 한 번에 너무 많은 파일을 봐서 주의가 흩어진 것이 원인입니다. 파일별 집중 패스와 파일 간 통합 패스로 나누는 선택지가 정답 쪽입니다.
