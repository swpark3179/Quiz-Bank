**repository**(저장소)의 줄임말로, Git 같은 버전 관리 시스템에서 **코드와 변경 이력을 담아 두는 곳**입니다. 팀원들이 *clone* 해서 함께 씁니다.

## 문제 속 쓰임
> ...three newly onboarded engineers who cloned the **repo** report that Claude Code ignores the conventions entirely...
> **저장소**를 클론한 신규 엔지니어 세 명은 Claude Code가 컨벤션을 완전히 무시한다고 보고한다.

## 함께 쓰는 표현
- **clone the repo** : 저장소를 복제해 받다
- **repo root** : 저장소 최상위 폴더
- **commit to the repo** : 저장소에 커밋하다

## 시험 포인트
팀 전체가 같은 규칙·커맨드를 써야 하면 **저장소에 커밋되는 프로젝트 범위**(`./CLAUDE.md`, `.claude/commands/`)에 두는 보기가 정답입니다. `~/.claude/` 는 내 머신에만 있어 클론한 팀원·CI에는 적용되지 않습니다.
