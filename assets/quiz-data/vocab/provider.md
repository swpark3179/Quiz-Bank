서비스·데이터·인증 같은 것을 **제공해 주는 쪽**을 말합니다. 기술 문서에서는 *identity provider*(로그인·신원을 확인해 주는 서비스)처럼 앞에 붙는 말로 무엇을 제공하는지 밝힙니다.

## 문제 속 쓰임
> Three turns earlier in the main conversation, the user chose a specific authentication **provider**.
> 메인 대화에서 세 턴 전에 사용자는 특정 인증 **공급자**를 골랐다.

## 함께 쓰는 표현
- **authentication provider** : 인증 공급자
- **identity provider (IdP)** : ID 공급자 (예: OIDC 제공자)
- **cloud provider** : 클라우드 사업자

## 비슷한 말 · 반대말
- **vendor / supplier** — 판매 업체 / 공급업체 (물품·계약 쪽에 더 자주 씀)

## 시험 포인트
공급자 이름 자체보다 **"세 턴 전에 사용자가 고른 결정"** 이 단서입니다. 서브에이전트는 새 컨텍스트로 시작해 부모 대화를 보지 못하므로, 코디네이터가 그 결정을 **위임 프롬프트에 직접 써 넣어야** 합니다.
