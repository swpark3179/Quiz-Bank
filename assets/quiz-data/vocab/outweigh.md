*out*(넘어서) + *weigh*(무게가 나가다)로, 저울에 달았을 때 **한쪽이 더 무거워 이긴다**는 뜻입니다. "이익이 비용보다 크다", "한 요인이 다른 요인보다 우선한다"처럼 씁니다.

## 문제 속 쓰임
> It runs, because the project allow rule and the flag together **outweigh** a single managed deny.
> 실행된다. 프로젝트 allow 규칙과 플래그가 합쳐져 managed deny 하나를 **이기기** 때문이다

## 함께 쓰는 표현
- **the benefits outweigh the costs** : 이익이 비용보다 크다
- **outweigh A** : A보다 중요하다, A보다 우선하다

## 비슷한 말 · 반대말
- **override** — (설정·결정을) 덮어쓰다
- **take precedence over** — ~보다 우선하다

## 시험 포인트
권한 규칙은 **개수로 겨루지 않습니다**. 어느 단계든 deny 가 하나라도 일치하면 막히고, managed 규칙은 프로젝트 allow 나 `--allowedTools` 플래그로도 뒤집을 수 없어 이 보기는 오답입니다.
