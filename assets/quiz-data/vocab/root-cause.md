겉으로 보이는 증상이 아니라, 그 증상을 만들어 낸 **가장 밑바닥의 원인**입니다. 이것을 고쳐야 같은 문제가 다시 생기지 않습니다.

## 문제 속 쓰임
> Which approach directly addresses the **root cause** of this self-review limitation?
> 이 자기 리뷰 한계의 **근본 원인**을 직접 해결하는 방법은?

## 함께 쓰는 표현
- **address / fix the root cause** : 근본 원인을 해결하다
- **root cause analysis (RCA)** : 근본 원인 분석
- **root-cause** (동) 근본 원인을 찾아내다 — *root-cause the bug*

## 비교
- **root cause** — 문제를 만든 근본 원인
- **symptom** — 겉으로 드러난 증상
- **workaround** — 원인은 그대로 두고 증상만 피해 가는 임시방편

## 시험 포인트
root cause 를 묻는 문제에서는 **증상만 가리는 보기**(사후 필터링, 더 큰 모델로 교체 등)를 먼저 지우세요. 정답은 보통 문제를 만든 지점(모호한 지시, 좁은 작업 분해, 같은 맥락의 자기 리뷰 등)을 직접 바로잡습니다.
