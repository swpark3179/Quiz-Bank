1. **(git) 브랜치** — 본줄기(main)에서 갈라져 따로 작업하는 갈래
2. **갈라지다, 분기하다** — 하나의 흐름이 여러 갈래로 나뉜다

## 문제 속 쓰임
> A team commits a `CLAUDE.md` file with: 'Never commit directly to main **branch**'.
> 팀이 "main **브랜치**에 직접 커밋하지 마라"는 내용의 `CLAUDE.md` 를 커밋했습니다.

## 함께 쓰는 표현
- **main / feature branch** : 기본 / 기능 브랜치
- **branch off** : (본줄기에서) 갈라져 나가다
- **branching** (명) 분기 — 조건에 따라 흐름이 나뉘는 것

## 시험 포인트
`CLAUDE.md` 의 "main 브랜치에 커밋 금지"는 **권고(맥락)일 뿐 강제가 아니라서**, 사용자가 요청하면 Claude Code 는 그대로 커밋합니다. 반드시 막아야 한다면 권한 설정·훅 같은 결정적 수단이 필요합니다.
