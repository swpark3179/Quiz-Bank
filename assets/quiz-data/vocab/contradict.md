한쪽이 말하는 내용을 다른 쪽이 **정면으로 부정해서 둘 다 참일 수 없는** 것입니다. 리뷰 문제에서는 **주석이 설명하는 동작과 실제 코드 동작이 어긋날 때** 씁니다.

## 문제 속 쓰임
> Specify explicit criteria: flag comments only when their claimed behavior **contradicts** actual code behavior.
> 명확한 기준을 정한다: 주석이 내세우는 동작이 실제 코드 동작과 **모순될** 때만 표시한다.

## 함께 쓰는 표현
- **contradictory feedback** : 서로 모순되는 피드백
- **contradiction** (명) 모순 · **contradict each other** 서로 모순되다

## 비교
- **contradict** — 서로 *정반대*라 함께 참일 수 없음
- **conflict** — 서로 *부딪침* (값·지침·이해관계 등 넓게 씀)
- **inconsistent** — 서로 *맞지 않음* (contradict 보다 약한 말)

## 시험 포인트
"정확한지 확인하라" 같은 모호한 지시 대신, **무엇을 문제로 볼지 검증 가능한 기준**(설명과 실제 동작이 contradict 할 때만)을 주는 선택지가 정답으로 나옵니다.
