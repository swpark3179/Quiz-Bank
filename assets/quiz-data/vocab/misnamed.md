*mis-*(잘못) + *named*(이름 붙은)로, **이름이 잘못 붙은** 것을 말합니다.

## 문제 속 쓰임
> ...teammates invoke it with no argument or a malformed one about a third of the time, producing empty or **misnamed** scaffolds.
> 팀원들이 약 3분의 1의 경우 인자 없이 또는 잘못된 형식의 인자로 호출해, 비어 있거나 **이름이 잘못된** 스캐폴드가 만들어집니다.

## 함께 쓰는 표현
- **misnamed file / variable** : 이름이 잘못 붙은 파일 / 변수
- **rename** : 이름을 바꾸다

## 시험 포인트
사람이 스킬을 **인자 없이·잘못된 인자로** 호출하는 실수가 잦으면, SKILL.md frontmatter 의 `argument-hint` 로 호출할 때 기대 형식을 보여 주는 보기가 정답입니다.
