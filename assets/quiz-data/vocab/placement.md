어떤 것을 **어느 자리에 두느냐**, 즉 놓는 위치를 말합니다. 프롬프트 문제에서는 텍스트를 시스템 프롬프트·사용자 메시지·도구 결과 중 어디에 넣는지를 가리킵니다.

## 문제 속 쓰임
> Predict what this **placement** does and where the text should go instead.
> 이 **배치**가 어떤 결과를 낳는지, 그리고 텍스트를 대신 어디에 두어야 하는지 예측하라.

## 함께 쓰는 표현
- **placement of instructions** : 지시를 두는 위치
- **placement in the system prompt** : 시스템 프롬프트에 두기
- **place** ~ **in / under** … : ~을 …에 두다

## 비슷한 말 · 반대말
- **position** — 위치 (비슷한 뜻)
- **arrangement / order** — 배열·순서. 여러 부분의 앞뒤 관계를 말할 때 씁니다

## 시험 포인트
웹 페이지·메일 같은 **제3자 텍스트의 자리는 `tool_result` 블록**입니다. 시스템 프롬프트에 "참고 자료"로 붙이면 개발자 지시와 같은 자리에 놓여 인젝션 위험이 커지므로 오답 신호입니다.
