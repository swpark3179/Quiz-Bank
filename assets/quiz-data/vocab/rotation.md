여러 대상이 **돌아가며 차례를 바꾸는** 것입니다. 기술 문서에서는 키·로그·순서 등을 주기적으로 바꿔 주는 일에 자주 씁니다.

## 문제 속 쓰임
> Implement **rotation** that alternates which subagent's results appear first across tasks.
> 작업마다 어느 서브에이전트 결과를 먼저 둘지 번갈아 바꾸는 **순환** 방식을 구현한다.

## 함께 쓰는 표현
- **key rotation** : API 키·자격 증명을 주기적으로 새것으로 교체하기
- **log rotation** : 로그 파일을 일정 주기마다 새 파일로 바꾸기
- **rotate** (동) 돌아가며 바꾸다, 교대하다
- **in rotation** : 차례로 돌아가며

## 시험 포인트
순서를 돌아가며 바꾸는 방법은 **평균적으로 공평해질 뿐**, 매번 긴 입력의 중간 내용이 묻히는 문제(lost in the middle)는 그대로 남습니다. 핵심 요약을 맨 앞에 두고 섹션 헤더로 정리하는 쪽이 근본 해결입니다.
