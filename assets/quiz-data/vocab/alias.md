실제 대상을 직접 적는 대신 **다른 이름으로 가리키는 포인터**입니다. 가리키는 대상이 나중에 바뀔 수 있다는 점이 고정된 ID와의 차이입니다.

## 문제 속 쓰임
> The code currently calls the **alias** `claude-haiku-4-5`.
> 코드는 현재 **별칭** `claude-haiku-4-5`를 호출한다.

## 함께 쓰는 표현
- **model alias** : 모델 별칭
- **snapshot ID** : 날짜가 붙은 고정 버전 ID (`claude-haiku-4-5-20251001`)
- **pin** : (버전을) 고정하다

## 비슷한 말 · 반대말
- **pointer** — 다른 것을 가리키는 값 (별칭을 설명할 때 쓰는 말)
- **fixed snapshot** — 바뀌지 않는 고정 버전

## 시험 포인트
4.6 이전 모델의 API 별칭은 그 마이너 버전의 **최신 날짜 스냅숏**을 가리키므로 바뀔 수 있습니다. 검토 없이 모델이 바뀌면 안 되면 정확한 스냅숏 ID로 고정합니다. 4.6 이후의 날짜 없는 ID는 별칭이 아니라 고정 스냅숏입니다.
