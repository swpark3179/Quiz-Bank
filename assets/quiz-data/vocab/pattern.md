## 문제 속 쓰임
> Write an exhaustive list in CLAUDE.md of every code **pattern** and the correct verdict for each one
> CLAUDE.md에 모든 코드 **패턴**과 각각의 올바른 판정을 망라한 목록을 작성한다.

## 함께 쓰는 표현
- **design pattern** : 디자인 패턴
- **anti-pattern** : 흔하지만 피해야 할 방식
- **match a pattern** : 패턴과 일치하다

## 시험 포인트
모든 패턴을 전부 나열하려는 보기는 오답이 되기 쉽습니다. 모호한 사례에서 판정이 들쭉날쭉하면 **판정 이유를 담은 대표 few-shot 예시 몇 개**가 정답입니다.
