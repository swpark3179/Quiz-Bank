1. **(결과를) 낳다, 내놓다** — 어떤 행동·입력이 결과로 ~을 만들어 낸다
2. **양보하다, 넘겨주다** — 제어권·우선권을 내어 줌 (*yield control*)

## 문제 속 쓰임
> Asking Claude to "make the input validation more robust and idiomatic" **yields** inconsistent output across runs...
> Claude에게 "입력 검증을 더 견고하고 관용적으로 만들어 줘"라고 요청하면 실행할 때마다 **들쭉날쭉한 결과가 나온다**...

## 함께 쓰는 표현
- **yield results / output** : 결과를 내다
- **yield control** : 제어권을 넘기다 (프로그래밍의 `yield` 키워드)

## 시험 포인트
모호한 요청이 실행마다 다른 결과를 낸다면, 원하는 스타일과 라이브러리를 그대로 보여 주는 **구체적인 입력-출력 예시 2~3개**를 주는 것이 정답입니다.
