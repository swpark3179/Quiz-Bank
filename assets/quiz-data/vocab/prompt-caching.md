요청마다 똑같이 들어가는 **프롬프트 앞부분(도구 정의·시스템 프롬프트·긴 문서)을 저장해 두고 다시 쓰는** 기능입니다. 캐시는 앞에서부터 일치하는 프리픽스 기준이라, 고정된 내용을 앞쪽에 두어야 이득을 봅니다.

## 문제 속 쓰임
> **Prompt caching** with the Message Batches API
> **프롬프트 캐싱**과 Message Batches API (함께 쓸 수 있는 조합)

## 함께 쓰는 표현
- **`cache_control`** : 캐시할 지점을 표시하는 필드
- **cache hit / cache read** : 캐시 적중 / 캐시 읽기
- **cached prefix** : 캐시된 앞부분

## 비슷한 말 · 반대말
- **batch processing** — 비동기 일괄 처리로 할인받는 다른 비용 절감 수단입니다. 캐싱과 겹쳐 쓸 수 있습니다

## 시험 포인트
캐싱은 배치·fast mode·데이터 레지던시와 **겹쳐 적용**되고, 함께 못 쓰는 조합은 **fast mode + 배치**입니다. 또 캐시된 토큰도 컨텍스트 창에는 그대로 계산되므로, 캐싱으로 컨텍스트 공간 문제를 풀 수는 없습니다.
