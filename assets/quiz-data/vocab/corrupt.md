파일·데이터가 **깨져서 정상적으로 읽을 수 없게 된** 상태를 말합니다. 사람·조직에 쓰면 "부패한"이라는 뜻이지만, 시험에서는 늘 데이터 이야기입니다.

## 문제 속 쓰임
> The document analysis subagent encounters a **corrupted** PDF file it cannot parse.
> 문서 분석 서브에이전트가 파싱할 수 없는 **손상된** PDF 파일을 만났다.

## 함께 쓰는 표현
- **corrupted file / data** : 손상된 파일·데이터
- **data corruption** : 데이터 손상
- **corrupt a file** : 파일을 손상시키다

## 시험 포인트
손상된 파일은 **다시 시도해도 결과가 같습니다**(일시적 오류가 아님). 재시도·지수 백오프 보기보다, 맥락과 함께 코디네이터에 보고해 판단을 맡기는 보기가 정답 쪽입니다.
