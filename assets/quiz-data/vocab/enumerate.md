여러 항목을 **하나하나 빠짐없이 열거하다, 나열하다** 라는 뜻입니다.

## 문제 속 쓰임
> Run a mapping pass **enumerating** the repository's real modules, then dynamically spawn one subagent per discovered component
> 저장소의 실제 모듈을 **열거하는** 매핑 단계를 먼저 실행한 뒤, 발견된 구성 요소마다 서브에이전트를 하나씩 동적으로 생성한다
> **Enumerating** every possible scenario in the prompt is impractical.
> 가능한 모든 시나리오를 프롬프트에 **나열하는** 것은 비현실적이다.

## 함께 쓰는 표현
- **enumerate all cases** : 모든 경우를 나열하다
- **enumeration** (명) 열거, 나열

## 시험 포인트
모든 경우를 규칙으로 **나열할 수 없는** 모호한 판정에는, 경계 사례에 대한 판단과 그 이유를 보여 주는 **few-shot 예시**를 넣는 보기가 정답입니다.
