겉으로 보이는 현상 **밑에 깔려 그것을 만들어 내는 근본적인** 것을 가리킵니다. 증상이 달라 보여도 원인이 같을 때 *the same underlying issue* 라고 합니다.

## 문제 속 쓰임
> General confidence language gives the model no concrete rule for what to report, so it still applies the same **underlying** judgment that produced the false positives before the change.
> 일반적인 확신 표현은 무엇을 보고할지에 대한 구체적 규칙을 주지 않으므로, 모델은 변경 전에 오탐을 만들던 **밑바탕의** 판단을 그대로 적용한다.

## 함께 쓰는 표현
- **underlying cause / issue** : 근본 원인·문제
- **underlying model** : (서비스 밑에서 돌아가는) 기반 모델
- **the same underlying** ~ : 밑바탕이 같은 ~

## 비슷한 말
- **root** — 근본의 (*root cause* 근본 원인)
- **fundamental** — 근본적인, 기본적인

## 시험 포인트
"높은 확신만 보고하라" 같은 막연한 말은 **무엇을 보고할지의 기준**을 바꾸지 않아서, 모델은 오탐을 만들던 *underlying* 판단을 그대로 씁니다. 정밀도를 올리려면 확신 문턱 대신 **명시적인 범주 기준**을 줘야 합니다.
