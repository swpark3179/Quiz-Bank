## 문제 속 쓰임
> Run each of the three changes in its own fresh session so every edit stays **cleanly** isolated from the others
> 세 변경을 각각 새 세션에서 실행해, 모든 수정이 서로 **깔끔하게** 격리되도록 한다

## 함께 쓰는 표현
- **cleanly separated / isolated** : 깔끔하게 분리된 / 격리된
- **exit cleanly** : 오류 없이 정상 종료하다

## 시험 포인트
변경들이 같은 enum·코드 경로를 공유해 서로 영향을 주면 **따로 깔끔하게 나누는** 것이 오히려 오답입니다. 한 메시지로 묶어 함께 수정하게 하는 것이 정답입니다.
