1. **할인(하다)** — *discounted* : 할인된
2. **(가능성·의견을) 가볍게 여기다, 무시하다** — *discount the risk*

## 문제 속 쓰임
> Move all rule violations to the Message Batches API and reprocess them overnight at the **discounted** batch rate.
> 규칙 위반 건을 모두 Message Batches API로 옮겨, **할인된** 배치 요금으로 밤사이 재처리한다

## 함께 쓰는 표현
- **at a discount** : 할인된 가격에
- **discounted rate / price** : 할인 요금·가격

## 시험 포인트
Message Batches API 는 요금이 **할인(약 50%)** 되는 대신 처리에 **최대 24시간**이 걸리고 지연 시간 보장이 없습니다. 밤사이 돌려도 되는 작업엔 맞고, 결과를 바로 기다려야 하는 작업엔 맞지 않습니다.
