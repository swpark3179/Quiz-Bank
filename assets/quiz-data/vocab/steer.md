배나 차의 방향을 조종하듯, 대상을 **원하는 쪽으로 이끄는** 것입니다. LLM 문맥에서는 프롬프트·지침이 모델의 행동을 특정 방향으로 **유도한다**는 뜻으로 자주 씁니다.

## 문제 속 쓰임
> The system prompt contains keyword-sensitive instructions that **steer** behavior based on terms like "account," creating unintended tool selection patterns.
> 시스템 프롬프트에 "account" 같은 용어에 따라 행동을 **유도하는** 키워드 민감 지침이 있어, 의도치 않은 도구 선택 패턴이 생긴다.

## 함께 쓰는 표현
- **steer A toward B** : A를 B 쪽으로 이끌다
- **steer clear of ~** : ~을 피하다
- **steering** (명) 조종, 방향 유도

## 비슷한 말
- **guide**, **direct** — 이끌다, 지시하다
- **nudge** — 슬쩍 한쪽으로 유도하다

## 시험 포인트
특정 단어가 들어갈 때만 행동이 **뚜렷하게 갈리면**, 모델 자체보다 그 단어에 반응하도록 쓰인 프롬프트 지침을 먼저 의심합니다.
