다른 사람(또는 별도 도구)이 변경된 코드를 **읽고 결함·개선점을 검토하는** 일입니다. *code-review* 처럼 하이픈을 붙이면 뒤 명사를 꾸밉니다(*code-review rubric* 코드 리뷰 루브릭).

## 문제 속 쓰임
> The project's always-loaded CLAUDE.md has grown to embed a long, detailed **code-review** rubric.
> 프로젝트의 항상 로드되는 CLAUDE.md에 길고 상세한 **코드 리뷰** 루브릭이 들어가 비대해졌습니다.

## 함께 쓰는 표현
- **code review comments** : 리뷰 코멘트
- **review rubric** : 리뷰 판정 기준표

## 시험 포인트
리뷰 작업에서만 필요한 긴 루브릭이 항상 로드되는 CLAUDE.md 에 있으면 **온디맨드 스킬**(`.claude/skills/<이름>/SKILL.md`)로 옮기는 것이 정답입니다. 또 리뷰는 코드를 만든 세션이 아닌 **독립 인스턴스**가 할 때 결함을 잘 찾습니다.
