CCA-F는 지식 시험이지만, 그 지식은 직접 Claude를 돌려 볼 때 비로소 자리 잡는다. 이 장에서는 시험 범위를 손으로 확인하기 위한 4가지 학습 환경을 준비한다.

설치 절차

01

계정 생성과 API 키 발급

Console · API Keys
  1. console.anthropic.com에 가입하고 이메일 인증을 마친다
  2. 왼쪽 메뉴 API Keys → Create Key, 알아보기 쉬운 이름(예: cca-f-study)을 붙인다
  3. 표시된 키(sk-ant-…)를 즉시 복사해 안전한 곳에 보관한다 — 발급 시 한 번만 표시된다
API 키 = 비밀번호

저장소에 push하거나 메신저에 붙여 넣지 않는다. 유출이 의심되면 Console에서 즉시 폐기(revoke)하고 새 키를 발급한다.

02

환경 변수 설정

ANTHROPIC_API_KEY
# ~/.zshrc (bash라면 ~/.bashrc)에 추가 export ANTHROPIC_API_KEY="sk-ant-xxxxxxxx" source ~/.zshrc # 반영 echo $ANTHROPIC_API_KEY # sk-ant-… 가 보이면 OK
03

curl로 첫 호출

Messages API smoke test
curl https://api.anthropic.com/v1/messages \ --header "x-api-key: $ANTHROPIC_API_KEY" \ --header "anthropic-version: 2023-06-01" \ --header "content-type: application/json" \ --data '{ "model": "claude-haiku-4-5", "max_tokens": 256, "messages": [ {"role": "user", "content": "Hello, Claude! 한 문장으로 자기소개해 주세요."} ] }'

응답 JSON의 content[0].text에 답변이 있으면 성공. 모델 ID는 예시이며, 실제 값은 Console의 Models 페이지·공식 문서에서 최신 ID를 확인한다.

비용 감각

동작 확인에는 가장 저렴하고 빠른 Haiku가 정석이다. Hello World에 최상위 모델을 쓰는 것은 낭비 — 용도별로 모델을 나눠 쓰는 습관을 처음부터 들인다.

06

MCP SDK와 샘플 서버

pip install mcp
from mcp.server.fastmcp import FastMCP mcp = FastMCP("hello-server") @mcp.tool() def greet(name: str) -> str: """이름을 받아 인사말을 돌려준다.""" return f"안녕하세요, {name}님!" if __name__ == "__main__": mcp.run()

python hello_mcp_server.py로 실행해 '돌아가는 환경이 있다'는 것만 확인하면 충분하다. 상세는 ⑦ MCP 입문에서 다룬다.

한국 환경 팁 (교재 편집부 보완)

망분리된 SI·금융권 환경이라면 ① api.anthropic.com으로의 아웃바운드가 사내 프록시·방화벽에서 허용되는지 확인한다 — Claude Code와 Python SDK 모두 HTTPS_PROXY 환경 변수를 지원한다. ② 직접 호출이 어렵다면 AWS Bedrock의 Claude 모델을 실습 대안으로 검토한다(리전·모델 제공 여부는 시점별로 확인). 시험은 Anthropic API 기준으로 출제된다.

흔한 오해

오해Claude Code를 설치하면 API도 같이 쓸 수 있는 같은 제품이다.
사실별개 도구다. Claude Code는 CLI 코딩 에이전트, API는 HTTP 엔드포인트. Claude Code가 내부적으로 API를 호출하므로 API 키는 공용으로 쓸 수 있다.
오해MCP는 Anthropic만의 독자 사양이다.
사실MCP는 오픈 사양이다. 다른 모델 제공자와 IDE도 지원한다 (modelcontextprotocol.io).

자가 점검 퀴즈

점수 0 / 5
Q1도구 구분
Claude Code와 Anthropic API의 관계를 가장 정확히 설명한 것은?
정답 (C)

둘은 별개다. 다만 Claude Code가 내부에서 API를 호출하므로 같은 API 키로 인증할 수 있다. 각각 claude --version, pip show anthropic으로 따로 확인한다.

Q2보안
실수로 API 키가 들어 있는 파일을 공개 저장소에 push했다. 가장 먼저 할 일은?
정답 (B)

이미 노출된 키는 이력·캐시에 남을 수 있으므로 삭제나 비공개 전환으로는 부족하다. 즉시 폐기하고 재발급하는 것이 원칙이다.

Q3모델 선택
설치 직후 'Hello' 수준의 동작 확인 요청을 보낼 때 가장 적절한 모델은?
정답 (A)

요건을 충족하는 가장 저렴한 모델을 고르는 것이 원칙이다. 단순 동작 확인에 상위 모델을 쓰는 것은 비용 낭비다.

Q4트러블슈팅
401 authentication_error가 반환됐다. 가장 가능성 높은 원인은?
정답 (D)

401은 인증 실패다. 모델 ID 문제는 404/not found, 레이트 리밋은 429, 파라미터 오류는 400으로 나타난다.

Q5Claude Code 설치
Node.js가 없는 새 PC에 Claude Code를 설치하려 한다. 교재 보완 노트가 권하는 방법은?
정답 (C)

네이티브 설치 프로그램이 기본 권장 방식이다. npm 설치도 지원되며 버전을 고정하거나 팀 표준이 npm일 때 유용하다 — 이때만 Node.js 18 이상이 필요하다.
