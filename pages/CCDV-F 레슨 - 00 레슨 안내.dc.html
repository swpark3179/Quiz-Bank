Claude Certified Developer – Foundations(CCDV-F)는 Claude로 애플리케이션을 직접 만드는 개발자를 위한 시험이다. 아키텍처 판단을 주로 묻는 CCAR-F와 달리, Messages API의 요청·응답 규칙, 모델 선택과 비용, 오류 처리, 보안·키 관리처럼 구현 단계의 구체적인 동작을 많이 묻는다. 이 가이드는 시험 범위를 8개 도메인, 25개 서브도메인으로 나누고 서브도메인 하나를 레슨 한 페이지로 다룬다. 내용은 Anthropic 공식 문서를 근거로 2026년 10월 기준으로 새로 썼다.

이 가이드 사용법
  • 왼쪽 메뉴에서 레슨을 고른다. 번호(1.1~8.3)는 시험 서브도메인 번호와 같다.
  • 레슨 맨 위 습득 포인트를 먼저 훑어보고, 다 읽은 뒤 각 항목을 스스로 설명할 수 있는지 확인한다.
  • 시험 판단 축 박스와 시험 함정에는 오답 보기에 자주 쓰이는 생각을 모았다.
  • 연습문제는 페이지에 넣지 않고 문제은행 앱 CCDV-F 카테고리에 도메인별로 모았다(영문 8세트 + 한글 8세트, 321문항씩). 레슨을 읽은 뒤 해당 도메인 세트를 푼다.

배점을 읽는 법
  • 배점은 채점 문항 중 그 도메인에서 나오는 대략적인 비율이다. 53문항이면 도메인 2에서 17~18문항, 도메인 5에서 9문항 안팎이 나오고, 도메인 3·4는 1~2문항씩이다.
  • 도메인 2·5만 합쳐도 절반이다. Messages API의 동작(2.3·5.2), 모델 선택과 비용(2.1·5.3·5.4)을 가장 탄탄하게 준비한다.
  • 배점이 작은 도메인도 다른 도메인과 겹친다. 예를 들어 훅(7.3)은 Agent SDK(1.2)와, 오류 처리(4.1)는 스트리밍(5.2)과 함께 나오기 쉽다.
  • 공개 자료에 따라 15/33/3/3/17/11/8/11%처럼 반올림한 값을 쓰기도 한다(합계 101%).

앱 CCDV-F 카테고리
  • 레슨 하나를 다 읽었다면 문제은행 앱의 CCDV-F 카테고리에서 해당 도메인 세트를 푼다. 영문 세트로 실제 시험 표현에 익숙해지고, 막히면 같은 번호의 한글 세트로 뜻을 확인한다. 두 세트의 문항·정답 번호는 같다.
